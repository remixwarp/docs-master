# Remove Miscellaneous Limits

This option lifts a handful of small Scratch limits that are not big enough to each get their own setting. Enable it in the [editor settings](/editor/settings) or with the [`limitless` URL parameter](/advanced/url-parameters).

With it enabled:

- The pitch sound effect range grows from 360 to 1000.
- Blocks that set or change sound effects or volume run instantly instead of pausing the script for a frame.
- The minimum pen size drops from 1 to 0, and the maximum pen size becomes unlimited (was 1200).
- Mouse X and Y are not rounded, which is useful at high resolution or in fullscreen.
- The music extension's limit of 30 simultaneous drums and notes is removed.

This list grows over time.
