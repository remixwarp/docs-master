# Wrapping up

That is the core of custom extension development. From here, the reference pages go deeper into each part of the API surface:

- [Scratch object API](/building-extensions/apis/scratch-api): the full `Scratch` object, block utility, and permission APIs.
- [VM API](/building-extensions/apis/vm-api): the runtime, targets, threads, and events.
- [Renderer API](/building-extensions/apis/renderer-api): drawing skins and drawables directly.
- [Audio API](/building-extensions/apis/audio-api): the audio engine, sound players, and effects.
- [Utility APIs](/building-extensions/apis/utility-apis): `Scratch.Cast` and related helpers in detail.

If you need native-speed blocks, the [compiled extensions](/building-extensions/compiled/overview) section shows how to generate JavaScript directly through RemixWarp's compiler.

## Getting help and contributing

You can browse the RemixWarp extension gallery, and find its submission instructions, at [extensions.bilup.org](https://extensions.bilup.org).
