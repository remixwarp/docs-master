RemixWarp has keyboard shortcuts for the common editor actions, and they are rebindable. Shortcuts shown with `Ctrl` use `Ctrl` on Windows and Linux and `⌘` (Command) on macOS.

## Default shortcuts

**File**

| Action | Shortcut |
| --- | --- |
| Save | `Ctrl+S` |
| Save as a copy | `Ctrl+Shift+S` |
| Load from computer | `Ctrl+O` |
| Package project | `Ctrl+P` |
| Restore points | `Ctrl+Shift+P` |

**Edit**

| Action | Shortcut |
| --- | --- |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z` |
| Copy | `Ctrl+C` |
| Paste | `Ctrl+V` |
| Cut | `Ctrl+X` |

**View**

| Action | Shortcut |
| --- | --- |
| Settings | `Ctrl+,` |
| Toggle fullscreen | `F11` |
| Toggle backpack | `Ctrl+Shift+B` |
| Toggle stage fullscreen | `Ctrl+Shift+F` |

**Project controls**

| Action | Shortcut |
| --- | --- |
| Start project (green flag) | `Ctrl+Enter` |
| Stop all | `Ctrl+Shift+Enter` |

**Editor navigation**

| Action | Shortcut |
| --- | --- |
| Spotlight search | `Ctrl+K` |
| Code tab | `Ctrl+1` |
| Costumes tab | `Ctrl+2` |
| Sounds tab | `Ctrl+3` |

**Libraries**

| Action | Shortcut |
| --- | --- |
| Sprite library | `Ctrl+Shift+A` |
| Costume library | `Ctrl+Shift+C` |
| Sound library | `Ctrl+Shift+M` |
| Extension library | `Ctrl+.` |
| Extension manager | `Ctrl+Shift+E` |

**Sprites and windows**

| Action | Shortcut |
| --- | --- |
| Duplicate sprite | `Ctrl+Shift+D` |
| Delete sprite | `Ctrl+Shift+X` |
| Close window | `Ctrl+Shift+K` |

Some features have their own keys that are not in this manager, such as the [find bar](/editor/find-bar) (`Ctrl+F`), [bookmarks](/editor/bookmarks) (`Ctrl+Alt+T` and `Ctrl+Alt+1` to `0`), the [variable manager](/editor/variable-manager) (`Ctrl+Shift+V`), and pause (`Alt+X`).

## The shortcut manager

Open **Settings** and go to the **Keyboard Shortcuts** page. It lists every rebindable shortcut, grouped by category, with a search box.

- To change one, click its **pencil** button, then press the new key combination. `Escape` cancels. If the combination is already used, the manager tells you which action holds it and refuses the clash.
- A changed shortcut shows a **Reset to default** button, and a **Reset all to defaults** button appears once you have any custom bindings.

Your custom bindings are saved to your browser and sync to your account when you are signed in, so they follow you across devices.
