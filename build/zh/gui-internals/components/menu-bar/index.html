菜单栏

菜单栏横跨编辑器顶部。它包含下拉菜单（文件、编辑、工具、书签）、设置按钮、项目标题，右侧是保存状态和账户。本页列出每个菜单和项目。

最左侧的 RemixWarp 徽标是到主页的链接。在窄窗口上，菜单折叠到 更多（☰）按钮后面；项目完全相同。

下面显示的键盘快捷键在 Windows/Linux 上使用 Ctrl，在 macOS 上使用 ⌘。完整列表在键盘快捷键中。

文件​

  • 新建 创建全新项目。如果当前项目有未保存的更改，会先警告您。
  • 新窗口（仅桌面应用）打开第二个编辑器窗口。
  • 立即保存（Ctrl+S）保存到项目当前所在的位置。当您已登录且项目属于您时，这会上传到 RemixWarp。请参阅项目管理。
  • 另存为副本（Ctrl+Shift+S）保存一个新的独立副本。
  • 改编 基于当前项目开始一个新项目。
  • 保存到 RemixWarp / 改编到 RemixWarp（登录Rotur 账户后显示）将项目上传到您的账户。上传本身从不发布项目；分享是在网站上单独进行的。
  • 查看项目页面 打开此项目在社区站点上的页面（项目存在于 RemixWarp 后显示）。
  • 从电脑加载（Ctrl+O）从磁盘打开 .sb3 文件。
  • 保存到（文件名） 和 另存为... 将 .sb3 保存到您的电脑。在支持文件系统访问 API 的浏览器上，您可以保存回同一文件；否则会正常下载。
  • 打包项目（Ctrl+P）在打包器中打开当前项目。
  • 提交到 Git...、推送到（远程）、从（远程）拉取 在项目有Git 仓库时出现。
  • 还原点（Alt+R）打开还原点管理器；创建还原点 立即创建一个。
  • 项目元数据 显示打开项目的作者、日期和内容。
  • 暂停自动保存 / 恢复自动保存 在自动保存开启时出现，并带有到下次自动保存的实时倒计时。

编辑​

  • 恢复角色 / 声音 / 造型 找回您最后删除的内容（没有可恢复内容时禁用）。
  • 撤销（Ctrl+Z）和重做（Ctrl+Shift+Z）作用于积木工作区。
  • 插件 打开插件设置。
  • 桌面设置（仅桌面应用）打开应用级选项。
  • 更改用户名 设置报告给项目和云变量的用户名。
  • 启用 / 禁用云变量 为本次会话切换云变量（在不可用时禁用）。
  • 显示教程 重播入门演练。
  • 帮助 打开编辑器内的帮助窗口，一个可搜索的编辑器、积木和扩展参考。
  • originChats 链接到 originChats 社区聊天。

模式​

模式菜单仅在编辑器偶尔出现的愚人节状态期间显示。它提供普通模式和猫咪模式（猫主题积木）。它对项目运行没有影响，并且一年中其他时间都关闭。

工具​

  • Git 打开版本控制窗口。
  • 终端 打开一个 shell 窗口。
  • 实时协作 打开实时协作。
  • 调试器和变量管理器 在这些工具可用时出现，分别打开调试器和变量管理器。
  • 添加扩展（Ctrl+.）打开扩展库以添加或导入扩展。
  • 管理扩展（Ctrl+Alt+E）列出项目中已加载的扩展。

书签​

书签菜单管理工作区书签：积木工作区中保存的相机位置，让您可以立即跳回脚本。在这里您可以添加、切换、重命名、删除、导出、导入和清除书签，并将它们组织到分类中。书签与项目一起存储。

快捷键：Ctrl+Alt+T 在当前位置添加书签；Ctrl+Alt+1 到 Ctrl+Alt+0 切换到前十个书签。

设置​

设置按钮打开设置窗口：主题、语言、编译器和运行时选项、自定义 FPS、自定义舞台大小等。

右侧​

菜单栏右侧的账户区域显示：

  • 保存状态，反映项目是否有未保存的更改。
  • 会话进行中时的实时协作存在指示器。
  • 到 RemixWarp 站点其余部分的导航。
  • 您的 Rotur 账户，或登录提示。登录启用保存到 RemixWarp、分享以及设置的云同步。

一个项目标题字段在您拥有该项目时位于中间。在项目页面上，您可能还会看到浏览量计数器、分享按钮、改编按钮和查看社区按钮，具体取决于项目和您是否已登录。反馈链接始终可用。
