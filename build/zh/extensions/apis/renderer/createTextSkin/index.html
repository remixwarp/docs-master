renderer.createTextSkin()

使用文本气泡创建器（如"说"或"思考"气泡）创建一个新的 SVG 皮肤。

语法​

renderer.createTextSkin(type, text, pointsLeft)

参数​

type​

类型： string

气泡类型：'say' 或 'think'。

text​

类型： string

气泡的文本内容。

pointsLeft​

类型： boolean

如果为 true，气泡尾部指向左侧；如果为 false，则指向右侧。

返回值​

类型： number

新皮肤的 ID。

示例​

const skinId = renderer.createTextSkin('say', 'Hello World!', true);
