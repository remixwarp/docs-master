造型和画板编辑器

每个角色都有一个或多个造型：它在舞台上显示的图像。舞台本身有背景，只是换了个名字的同一事物。造型标签页（选中舞台时叫背景）列出它们并打开内置画板编辑器进行绘制和编辑。

造型列表​

造型列表位于造型标签页的左侧。每个条目显示缩略图、造型名称和以舞台单位计的大小。点击造型选择它并在舞台上显示；角色的当前造型是高亮的那一个。

右键单击造型可以获得复制、导出（将图像以 .svg 或 .png 保存到电脑）和删除。您不能删除角色最后一个剩余的造型。拖动造型重新排序；顺序就是 下一个造型 积木遍历的顺序。

添加造型​

列表底部的圆形添加按钮提供：

  • 选择一个造型 / 选择一个背景：从内置素材库中选择。
  • 上传造型 / 上传背景：从电脑加载图像。接受的类型是 .svg、.png、.bmp、.jpg、.jpeg、.jfif、.webp 和 .gif。您可以一次选择多个文件，每个都会成为一个造型。
  • 随机：从素材库中添加随机造型。
  • 绘制：创建空白造型并开始绘制。
  • 搜索：按名称浏览素材库。

您也可以从背包拖入造型。

位图和矢量​

画板编辑器以两种模式工作，每个造型是其中一种：

  • 矢量造型由形状（路径、椭圆、矩形、文本）组成。它们在任何尺寸下都保持清晰，并且是新造型的默认模式。Scratch 自己的美术是矢量。
  • 位图造型是像素网格，像照片或 .png。它们适合像素艺术和导入的照片，但放大时会模糊。

画布底部的一个按钮在它们之间切换：转换为位图或转换为矢量。转换会栅格化或描摹美术作品，因此往返并不总是无损的。

矢量工具​

打开矢量造型时，画布左侧的工具是：

  • 选择：移动、调整大小、旋转和分组形状。
  • 变形：拖动路径的各个点和曲线手柄。
  • 画笔和线条：绘制徒手笔画和直线。
  • 橡皮擦：擦除形状的部分。
  • 填充：用颜色或渐变填充区域。
  • 文本：添加可编辑文本。
  • 圆形和矩形（包括圆角矩形）：绘制填充或轮廓形状。

顶部是填充和轮廓颜色选择器（每个都支持纯色或渐变）、笔划宽度，以及分组/取消分组、将形状前移或后移、水平或垂直翻转以及复制/粘贴的操作。

位图工具​

打开位图造型时，工具集变为像素对应物：画笔、线条、圆形、矩形、文本、填充（油漆桶）、橡皮擦和选择。这里填充也支持纯色和渐变。

造型画布​

  • 画布中心的十字准线标记角色的旋转中心，即它围绕旋转的点，也是放置在其 x/y 位置的点。拖动它，或使用居中控件，来更改造型的枢轴。
  • 缩放控件位于画布的右下角。
  • 撤销和重做在编辑器顶部，画布聚焦时常用的 Ctrl+Z / Ctrl+Shift+Z 快捷键也有效。
