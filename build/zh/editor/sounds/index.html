声音和声音编辑器

每个角色和舞台都可以持有声音：您用声音积木播放的音频剪辑。声音标签页列出它们并打开内置声音编辑器，您可以在不离开 RemixWarp 的情况下录制、修剪和应用效果。

声音列表​

声音出现在声音标签页的左侧，每个都有名称和以秒为单位的长度。点击一个进行选择和编辑。右键单击获得复制、导出（将剪辑保存到电脑）和删除。

添加声音​

底部的圆形添加按钮提供：

  • 选择一个声音：从内置素材库中选择。
  • 上传声音：加载音频文件。接受的类型是 .wav、.mp3、.ogg、.flac、.aac 和 .m4a。您可以一次选择多个。
  • 随机：从素材库中添加随机声音。
  • 录制：从麦克风捕获音频（见下文）。

录制​

录制打开录音机。授予麦克风访问权限，按下录制，完成后停止。您会得到一个带修剪手柄的波形，因此您可以在将其保存为新声音之前将录音剪切到只保留想要的部分。录制需要正常的麦克风和浏览器音频支持。

声音编辑器​

选择声音会显示它的波形。控件是：

  • 播放 / 停止（也可以用空格键切换）。
  • 在波形上拖动做出选择。时间读数显示当前选择的位置和长度，如果没有选择则显示整个声音。按 Escape 或 Ctrl+A 清除或全选。
  • 修剪：做出选择后，删除（或 Delete / Backspace 键）移除它。Shift+Delete 只保留选择并删除其他所有内容。
  • 复制、粘贴和复制到新声音（将选择变成全新的声音）。标准的 Ctrl+C / Ctrl+V 也有效。
  • 撤销和重做（Ctrl+Z / Ctrl+Shift+Z），最多 99 步。

效果应用于选择，如果没有选择则应用于整个声音：

  • 加速和减速更改播放速率和音调。
  • 放大和减小更改音量（当剪辑已经接近削波时，放大被禁用）。
  • 静音使选择静音。
  • 淡入和淡出在边缘渐变音量。
  • 反转反向播放音频。
  • 机器人添加金属质感、音高变化的纹理。
  • 回声添加重复的回声。

备注​

  • 编辑器以单声道工作。编辑立体声声音会先警告您，因为保存编辑会将其永久转换为单声道。
  • 波形下方是剪辑的采样率、声道数和文件大小。非常大的声音会显示警告，说明它们可能太大而无法上传。
  • 声音编辑对存储的资产是破坏性的，但编辑器打开时完全可撤销。
