项目管理

本页涵盖项目的生命周期：开始新项目、保存它（到电脑或您的 RemixWarp 账户）、重新加载它、分享它和改编它。这些操作中的大多数位于文件菜单中。

新项目​

文件，新建清空工作区并开始一个带一个角色（Misty）的全新项目。如果当前项目有未保存的更改，会先警告您，因为新项目会替换打开的内容。

保存​

项目可以保存到两个独立的地方：作为文件保存到电脑，或在线保存到您的 RemixWarp 账户。它们不冲突；一个项目可以同时保存到两者。

保存到电脑​

  • 文件，保存到（文件名）或另存为将 .sb3 文件写入磁盘。在支持文件系统访问 API 的浏览器上，保存可以写回您打开的文件；否则会正常下载。
  • 文件，从电脑加载（Ctrl+O）从磁盘打开 .sb3。

.sb3 是一个单一的自包含文件：一个 ZIP 归档，包含 project.json（所有角色、脚本、变量和设置）以及每个造型和声音。它是项目的可移植、离线副本，可在 Scratch、TurboWarp 和 RemixWarp 中工作。

保存到 RemixWarp​

当您用Rotur 账户登录时，文件菜单显示保存到 RemixWarp（项目存在于那里后，立即保存 / Ctrl+S 会保存到您的账户）。这会将项目上传到您的账户，让您可以通过社区站点从任何设备访问它。

  • 上传不是发布。已保存的项目在您分享之前对您保持私有。
  • RemixWarp 高效上传资源，只发送它尚未拥有的造型和声音，因此重新保存项目很快。

要制作独立保存的副本，请使用文件，另存为副本（Ctrl+Shift+S）。

分享​

分享是在社区站点上进行的，而不是通过编辑器的保存操作。项目保存到您的 RemixWarp 账户后，打开它的项目页面（文件，查看项目页面，或菜单栏中的账户区域）并使用那里的分享按钮。分享使项目对他人可见，并给它一个公开页面和播放器。您从站点控制可见性。

改编​

改编基于现有项目开始一个新项目，并注明原作者。文件，改编（登录时是改编到 RemixWarp）创建您自己的副本，您可以更改并单独保存，不会触及原件。改编是您基于别人的共享项目构建的方式。

自动保存与还原点​

您工作时有两个安全网在运行：

  • 还原点定期将整个项目快照到您的浏览器中，这样您可以在出错或崩溃后回滚。
  • 可选的自动保存按计时器将项目重新保存到当前位置。

两者都不能取代刻意保存，但都能降低忘记保存的代价。
