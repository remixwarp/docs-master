安装

RemixWarp 是免费开源的。没有任何需要购买的东西，网页版也无需安装。您可以通过三种方式使用它：在浏览器中、作为桌面应用，或者作为单个项目的打包独立构建。

在网页上使用​

在任何现代浏览器中打开 remixwarp.pages.dev。编辑器加载完成后即可立即开始创作。创建、编辑、保存到电脑或打开 .sb3 文件都不需要账户。

当您想要以下功能时，可以使用 Rotur 账户登录：

  • 将项目发布到 RemixWarp 社区，
  • 关注他人、评论并显示在您的个人资料中，
  • 在设备之间同步设置和主题。

这些功能以后再做也可以；开始创作并不需要账户。

保存工作成果​

没有账户时，使用 文件然后保存到电脑 下载 .sb3 文件，使用 文件然后从电脑加载 重新打开。有账户时，文件然后保存到 RemixWarp 会将项目发布到社区平台并保存在您的账户中。完整的保存与分享流程请参阅项目管理。

桌面应用​

RemixWarp 有一个桌面应用，可以在自己的窗口中运行相同的编辑器，而不是浏览器标签页。桌面版增加了网页无法提供的便利功能，例如多编辑器窗口和原生文件处理。请从 github.com/RemixWarp/desktop/releases 下载当前版本。

桌面应用是可选的。所有核心功能在网页版中都可用。

打包项目​

02Engine Packager 可以将单个项目转换为可分发独立程序：HTML 文件、zip 压缩包或原生可执行文件，所有这些都不需要编辑器即可运行。这不是 RemixWarp 本身的安装程序；而是用于制作项目的构建工具。

您可以通过 文件然后打包项目（Ctrl+P）将当前项目直接发送到打包器。更多选项（如离线构建、自定义舞台缩放和商业用途）请参阅打包器概览。

浏览器支持​

RemixWarp 支持当前版本的 Chrome、Edge、Firefox 和 Safari。它需要 JavaScript、WebGL 和 Web Audio API，这些浏览器默认都提供。如果舞台无法渲染，请检查浏览器设置中是否启用了硬件加速和 WebGL。
