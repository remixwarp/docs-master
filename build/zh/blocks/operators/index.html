运算积木

运算积木进行数学运算、比较值、组合逻辑并操作文本。它们都是报告积木或布尔积木，因此它们插入其他积木的凹槽，而不是独立存在。

数学​

  • ( ) + ( )、-、*、/ 是加法、减法、乘法和除法。
  • 在 1 和 10 之间取随机数 返回范围内的随机数。如果两个输入都是整数，则返回整数，否则返回小数。
  • ( ) 除以 ( ) 的余数 返回余数（使用向下取整除法，因此结果与除数符号一致）。
  • ( ) 四舍五入 四舍五入到最近的整数。
  • 绝对值 / 向下取整 / 向上取整 / 平方根 / sin / cos / tan / asin / acos / atan / ln / log / e^ / 10^ 的 ( ) 应用从菜单中选择的数学函数。

比较与逻辑​

  • ( ) < ( )、( ) = ( )、( ) > ( ) 比较两个值。
  • < > 且 < >、< > 或 < > 组合两个布尔值。
  • 不成立 < > 反转布尔值。

文本​

  • 连接 苹果 和 香蕉 将两个值连接成一个字符串。
  • 苹果 的第 1 个字符 按位置返回单个字符。
  • 苹果 的字符数 返回字符数。
  • 苹果 包含 a ? 报告文本是否包含子字符串（不区分大小写）。

RemixWarp 和 TurboWarp 额外积木​

这些运算积木不在标准 Scratch 中：

  • 苹果 的第 1 到 3 个字符 返回两个位置之间的子字符串。
  • 苹果 中 项目 的位置（index_of）返回子字符串的位置，如果未找到则为 0（不区分大小写）。
  • 将 苹果 中的 a 替换为 - 替换子字符串的每次出现（不区分大小写）。
  • ab 重复 3 次 将字符串重复若干次。
  • 将 Apple 转为 大写 / 小写 更改文本的大小写。
  • 修剪 苹果 移除前导和尾随空白。
  • 将 5 限制在 0 和 10 之间 将数字限制在一个范围内。
  • ( ) 和 ( ) 的较小值 / 较大值 返回较小或较大的值（这些接受两个以上的操作数）。
  • 圆周率 报告常数 3.14159...，方便进行圆相关数学计算。
  • 换行符 报告换行字符，用于构建多行字符串。

完整的列表请参阅RemixWarp 额外积木。
