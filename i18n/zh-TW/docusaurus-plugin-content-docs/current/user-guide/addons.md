插件是改變編輯器外觀和行為的可選附加組件，從小的便利功能到全新的工具。每個插件都可以獨立打開或關閉，許多有自己的設置。它們隻影響您的編輯器；不會改變項目分享時的運行方式。

## 打開插件設置

打開**編輯**菜單並選擇**插件**。這會打開插件設置窗口，一個可搜索的每個插件列表，每個插件都有一個開關。

## 使用列表

- 用它的複選框**啟用或禁用**插件。更改立即生效。
- **每插件設置**：展開插件查看它自己的選項（複選框、下拉框、顏色選擇器等）。
- **預設**：某些插件提供一次應用一組設置的命名預設。
- **重置**：每個插件都有一個重置按鈕，恢復其默認值。
- 按名稱、描述或設置**搜索**，並**按標籤篩選**以縮小列表。插件帶有如**推薦**、**主題**、**測試版**、**新**和**危險**（可能有干擾性）等標記。

在窗口底部，**全部重置**將每個插件恢復為默認值，**導出**和**導入**將您的整個插件配置保存為文件或從中加載，這便於在瀏覽器之間移動您的設置或分享它。

## 備註

- 一些以插件開始的特性現在直接內置到 RemixWarp 中，並在[設置](/user-guide/settings)頁面上配置，而不是在這裡。
- 插件設置存儲在您的瀏覽器中，並在登錄時同步到您的賬戶。
