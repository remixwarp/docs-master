RemixWarp 編輯器是您構建項目的地方。它完全在瀏覽器中運行（也可以在桌面應用中），並與社區站點來自同一構建。本頁是編輯器窗口的地圖：每個區域是什麼以及在哪裡閱讀更多內容。

## 佈局一覽

編輯器分為幾個固定區域：

- **菜單欄**橫跨頂部：RemixWarp 徽標（返回主頁的鏈接）、文件 / 編輯 / 工具 / 書籤菜單、設置、項目標題，右側是保存狀態和賬戶。請參閱[菜單欄](/user-guide/menu-bar)。
- **舞臺**在一邊：運行中的項目、綠旗和停止按鈕、舞臺大小控件和全屏按鈕。請參閱[舞臺](/user-guide/stage)。
- **角色面板**在舞臺下方：角色列表、所選角色的屬性（位置、大小、方向、可見性）以及舞臺/背景選擇器。請參閱[角色](/user-guide/sprites)。
- **編輯區域**佔據窗口的其餘部分，由左上角的三個標籤頁控制：
  - **代碼**：[積木區](/user-guide/blocks-palette)和[積木工作區](/user-guide/workspace)。
  - **造型**（選中舞臺時是**背景**）：[畫板編輯器](/user-guide/costumes)。
  - **聲音**：[聲音編輯器](/user-guide/sounds)。

三個標籤頁切換編輯區域為當前選中的角色或舞臺顯示的內容。舞臺、角色面板和菜單欄在切換標籤頁時保持不變。

## 編輯器模式與播放器模式

同一個頁面可以兩種方式渲染。在**編輯器模式**下您會看到上面所有內容。在**播放器模式**下只顯示舞臺及其控件，這是訪問者在共享項目頁面或嵌入中看到的。社區項目頁面將項目加載到嵌入的播放器中，而不是完整的編輯器。

## RemixWarp 編輯器有何不同

除了標準的 Scratch 佈局，RemixWarp 編輯器還增加了：

- 一個將您的積木轉換為 JavaScript 以提高速度的[編譯器](/user-guide/overview)，以及[自定義 FPS](/website/custom-fps)、[自定義舞臺大小](/website/custom-stage-size)和其他[高級設置](/user-guide/settings)。
- 重塑和重設編輯器樣式的[插件](/user-guide/addons)和[自定義主題](/user-guide/themes)。
- 開發者工具：[調試器](/user-guide/debugger)、[變量管理器](/user-guide/variable-manager)、[還原點](/user-guide/restore-points)和自動保存、內置的[Git 版本控制](/user-guide/git)以及[實時協作](/user-guide/collaboration)。
- 用於在大型項目中導航的[查找欄](/user-guide/find-bar)和[工作區書籤](/user-guide/bookmarks)。
