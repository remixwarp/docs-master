# LEGO BOOST

**LEGO BOOST**擴展控制 LEGO BOOST 移動集線器，包括它的馬達、顏色傳感器和傾斜偵測。它是內置的，並且與 Scratch 兼容。

從**添加擴展**加載它並選擇 **LEGO BOOST**。

## 要求

BOOST 通過藍牙連接，因此您需要：

- 一臺帶藍牙和支持的瀏覽器的電腦。
- **Scratch Link** 運行以將藍牙橋接到瀏覽器。
- BOOST 移動集線器與您的電腦配對。

添加擴展會打開連接窗口以配對集線器。

## 積木

### 將馬達 `[馬達]` 開啟 `[時長]` 秒

運行馬達一段設定時間。

### 將馬達 `[馬達]` 開啟 `[轉數]` 轉

運行馬達一定轉數。

### 將馬達 `[馬達]` 開啟 / 關閉

啟動或停止馬達。

### 將馬達 `[馬達]` 速度設為 `[功率]` %

將馬達速度從 0 設置為 100 百分比。

### 將馬達 `[馬達]` 方向設為 `[方向]`

將馬達設置為**朝這個方向**、**朝那個方向**或**反轉**運行。

### 馬達 `[馬達]` 位置

馬達旋轉位置的報告積木。

### 當看到 `[顏色]` 積木 / 看到 `[顏色]` 積木?

響應顏色傳感器檢測到彩色積木，作為帽子積木或布爾積木。

### 當傾斜 `[方向]` / 傾斜角度 `[方向]`

響應傾斜集線器，或讀取它的傾斜角度。

### 將燈光顏色設為 `[色相]`

設置集線器內置燈光的顏色。
