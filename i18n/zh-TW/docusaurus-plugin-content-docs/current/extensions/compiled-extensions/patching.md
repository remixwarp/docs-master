# 補丁

**補丁**擴展讓您在積木中編寫原始 JavaScript。項目編譯時，該 JavaScript 被直接注入生成的代碼中，並作為編譯線程的一部分運行。它是內置的，並被標記為與 Scratch 不兼容。

從**添加擴展**加載它並選擇**補丁**。

## 積木

### js `[代碼]`（報告）

```scratch
(js [1 * 3])
```

計算 JavaScript 表達式並返回其值。默認文本是 `1 * 3`，報告 `3`。

### js `[代碼]`（布爾）

```scratch
<js [1 === 1]>
```

計算 JavaScript 表達式並將其作為布爾值報告。

### js `[代碼]`（命令）

```scratch
js [console.log("hello")]
```

將 JavaScript 作為語句運行，用於產生副作用。默認文本將 `hello` 記錄到控制台。

## 需要編譯器

補丁積木只在編譯器開啟時工作。積木體被拼接到編譯輸出中；沒有解釋器回退，因此如果編譯器被禁用，積木會拋出 `補丁積木需要編譯器`。確保編譯器已啟用（默認啟用）。編譯如何控制請參閱[禁用編譯器](/website/disable-compiler)。

## 安全與穩定性風險

::::warning
補丁以與頁面其餘部分相同的訪問權限運行您放入積木中的任何 JavaScript。請像對待您從互聯網粘貼的任何代碼一樣對待它。
::::

- 只使用您理解的代碼。補丁積木可以讀取和更改項目能做的任何事情，包括髮出網絡請求。
- 除非您信任作者，否則永遠不要加載使用補丁積木的共享項目，原因相同。
- 因為代碼被注入編譯輸出中，語法錯誤或運行時異常可能破壞整個編譯線程，而不只是那一個積木。
- 表達式形式（`js` 報告和布爾）應該是一個單個表達式。命令形式接受語句。

要以結構化的方式編寫參與編譯項目的 JavaScript，請參閱[編譯擴展](/extensions/compiled/overview)，這是超出快速一行之外任何內容的受支持路徑。
