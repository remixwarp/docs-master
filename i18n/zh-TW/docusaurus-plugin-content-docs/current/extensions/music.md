# 音樂

**音樂**擴展使用內置的合成聲音集播放樂器音符和鼓聲。它是內置的，可以離線工作，並且與 Scratch 兼容。它與 Scratch 中的音樂擴展相同。

從**添加擴展**加載它並選擇**音樂**。

## 積木

### 擊打 `[鼓]` 拍

```scratch
擊打 (1 v) (0.25) 拍
```

播放 18 種打擊樂聲音之一（小軍鼓、低音鼓、邊擊、碎音鈸、開閉踩鑔、鈴鼓、拍手、響木、木魚、牛鈴、三角鐵、邦戈鼓、康加鼓、卡巴薩、刮鬍、顫音鞭、奎卡）持續給定的拍數，然後繼續。

### 休止 `[拍數]` 拍

```scratch
休止 (0.25) 拍
```

不播放任何聲音地等待給定的拍數。

### 彈奏音符 `[音符]` 拍

```scratch
彈奏音符 (60) (0.25) 拍
```

在當前樂器上播放一個音符（作為 MIDI 音符編號，用鋼琴鍵選擇器選擇）持續給定的拍數。

### 將樂器設為 `[樂器]`

```scratch
將樂器設為 (1 v)
```

為此角色選擇*彈奏音符*使用的樂器。有 21 種樂器，包括鋼琴、電鋼琴、風琴、吉他、電吉他、貝斯、撥絃、大提琴、長號、單簧管、薩克斯、長笛、木笛、巴松、合唱、顫音琴、八音盒、鋼鼓、馬林巴、合成主音和合成墊。

### 將速度設為 `[速度]`

```scratch
將速度設為 (60)
```

以每分鐘節拍數設置速度。速度越高，音符和鼓播放得越快。

### 將速度增加 `[速度]`

```scratch
將速度增加 (20)
```

添加到當前速度。

### 速度

```scratch
(速度)
```

當前以每分鐘節拍數為單位的速度的報告積木。

## 提示

- "拍"由速度定義，因此相同的*拍數*值根據速度以不同的真實時長播放。
- 樂器和速度是每角色的，因此不同角色可以同時播放不同的樂器。
- 不需要互聯網或硬件。所有聲音都在本地生成。
