# 結束

那是自定義擴展開發的核心。從這裡開始，參考頁面深入 API 表面的每個部分：

- [Scratch 對象 API](/extensions/apis/scratch-api)：完整的 `Scratch` 對象、積木工具和權限 API。
- [VM API](/extensions/apis/vm-api)：運行時、目標、線程和事件。
- [渲染器 API](/extensions/apis/renderer-api)：直接繪製皮膚和可繪製對象。
- [音頻 API](/extensions/apis/audio-api)：音頻引擎、聲音播放器和效果。
- [實用 API](/extensions/apis/utility-apis)：`Scratch.Cast` 和相關輔助工具的詳細內容。

如果您需要原生速度的積木，[編譯擴展](/extensions/compiled/overview)部分展示瞭如何通過 RemixWarp 的編譯器直接生成 JavaScript。

## 獲取幫助和貢獻

您可以在 [extensions.bilup.org](https://extensions.bilup.org) 瀏覽 RemixWarp 擴展畫廊，並找到它的提交說明。

感謝您讀到這裡。
