# micro:bit

**micro:bit**擴展將項目連接到 BBC micro:bit，一個帶按鈕、運動偵測、LED 顯示屏和輸入引腳的小型可編程板。它是內置的，並且與 Scratch 兼容。

從**添加擴展**加載它並選擇 **micro:bit**。

## 要求

micro:bit 通過藍牙與 RemixWarp 通信，因此您需要：

- 一臺帶藍牙和支持它的瀏覽器的電腦。
- **Scratch Link**（或 Scratch 應用）運行以將藍牙橋接到瀏覽器。
- Scratch micro:bit HEX 固件刷寫到板上。

添加擴展時，會出現連接窗口，讓您配對板子。如果配對失敗，請檢查 Scratch Link 是否在運行以及固件是否已安裝。

## 積木

### 當按下 `[按鈕]` 按鈕

一個在**A**、**B**或**任意**按鈕被按下時運行的帽子積木。

### `[按鈕]` 按鈕被按下?

一個報告給定按鈕當前是否被按住的布爾積木。

### 當 `[手勢]`

一個在**移動**、**搖動**或**跳躍**等運動手勢時運行的帽子積木。

### 顯示 `[矩陣]`

在 5 乘 5 的 LED 顯示屏上點亮一個圖案。點擊積木編輯哪些 LED 亮著。

### 顯示文字 `[文本]`

在 LED 顯示屏上滾動顯示一條短消息。

### 清空顯示

關閉每個 LED。

### 當傾斜 `[方向]` / 傾斜 `[方向]`? / 傾斜角度 `[方向]`

響應向**前**、**後**、**左**、**右**或**任意**方向傾斜板子，或將傾斜角度讀取為數字。

### 當引腳 `[引腳]` 接通

一個在通過 micro:bit 引腳之一完成電路時運行的帽子積木，因此您可以連接自己的按鈕。
