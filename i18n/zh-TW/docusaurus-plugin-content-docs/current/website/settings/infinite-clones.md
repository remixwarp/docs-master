# 無限克隆

Scratch 將項目同時存在的克隆限制為 300 個。此選項移除該上限，讓您可以創建任意數量的克隆。可以在[編輯器設置](/user-guide/settings)中啟用，或通過 [`clones` URL 參數](/website/url-parameters)（`clones=1000`）設置明確上限。

::::caution
有些項目依賴 Scratch 在超過限制後拒絕創建更多克隆。當限制被移除時，這些項目可能會出現異常。創建非常大量的克隆也會使項目變慢或耗盡內存。
::::
