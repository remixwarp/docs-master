# 翻譯

**翻譯**擴展將文本翻譯成其他語言，並告訴您觀看者自己的語言。它是內置的，並且與 Scratch 兼容。翻譯由 Google 提供。

從**添加擴展**加載它並選擇**翻譯**。

## 需要互聯網

翻譯由在線服務完成，因此此擴展每次翻譯都需要互聯網連接。離線時，翻譯積木不會返回結果。

## 積木

### 將 `[文字]` 翻譯為 `[語言]`

```scratch
(將 [你好] 翻譯為 (西班牙語 v))
```

一個報告積木，返回給定文本翻譯成所選語言的結果。從下拉框中選擇目標語言。

### 語言

```scratch
(語言)
```

一個報告積木，返回觀看者自己的語言（他們的瀏覽器或設備設置的語言）。將其與*將 ... 翻譯為*結合，可以自動以運行項目的人使用的任何語言顯示文本。

## 提示

- 機器翻譯是近似值。簡短、樸實的句子比習語或俚語翻譯得更可靠。
- 使用*語言*報告積木作為*將 ... 翻譯為*的目標，可以為每個觀看者即時本地化您的項目。
