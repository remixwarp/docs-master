# 雲變量

雲變量是其值在打開同一項目的所有人之間實時共享的變量。當變量名以雲符號（`☁`）開頭時，它就是雲變量。您可以像在 Scratch 中一樣，在"新建變量"對話框中勾選"雲變量"來創建。

雲變量是項目構建排行榜、訪客計數器、簡單多人遊戲和其他共享狀態的方式。

## 基礎知識

- **只能存數字。** 雲變量只能保存數字。要共享文本，請將其編碼為數字並在另一端解碼。
- **連接期間共享。** 只有在用戶停留在項目中時，值才存在於雲服務器上。沒有長期歷史記錄，服務器重啟或項目長時間為空時值可能會重置。請勿將雲變量當作永久存儲。
- **所有觀看者都能看到變化。** 當一個玩家更改雲變量時，連接到同一項目的其他人會很快看到新值。

RemixWarp 默認連接到一個共享的雲服務器（`wss://clouddata.turbowarp.org`），與 TurboWarp 使用的是同一個。項目可以創建的雲變量數量沒有限制（Scratch 限制為 10 個）。

## 雲變量無法連接的情況

雲變量需要同時滿足以下所有條件：

- 項目中至少有一個雲變量。
- 您正在播放器中查看項目，而不是在編輯。當您編輯無法保存的項目時，雲變量會被禁用，以避免編輯干擾實時數據。
- 項目沒有使用[視頻偵測](/extensions/video-sensing)擴展。出於隱私原因，只要視頻偵測處於活動狀態，雲變量就會被禁用，這樣項目就無法悄悄通過網絡傳輸攝像頭數據。

## 選擇不同的服務器 {#cloud-host}

您可以通過 [`cloud_host` URL 參數](/advanced/url-parameters#accounts-and-cloud) 將項目指向不同的雲服務器：

```
https://remixwarp.pages.dev/12785898?cloud_host=wss://clouddata.turbowarp.org
```

請使用 `wss://`（安全）URL。不安全的 `ws://` 服務器通常會失敗，因為 RemixWarp 通過 HTTPS 提供服務。您無法通過這種方式連接 Scratch 自己的雲服務器，因為這需要 RemixWarp 沒有的 Scratch 賬戶憑據。

## 處理數字以外的數據

由於只允許數字，需要列表、文本或結構化數據的項目通常會將所有內容編碼為一個長數字或帶分隔符的數字字符串，並在讀取時解碼。這是常見的 Scratch 技巧，在 RemixWarp 中同樣有效。請保持更新頻率較低（見下文）並讓值的大小保持合理。

## 面向機器人和庫開發者 {#advanced}

雲協議與 [Scratch 的協議相同](https://github.com/TurboWarp/cloud-server/blob/master/doc/protocol.md)，因此您可以編寫自己的客戶端或機器人。這是一項由志願者運營的免費服務，以下幾條規則可以確保大家都能正常使用：

- **發送 `User-Agent`**，包含聯繫方式（個人資料鏈接、郵箱或問題跟蹤器），如果適用，還包括您的庫名稱和版本。瀏覽器客戶端無法設置此項，這沒問題，因為瀏覽器會改為發送 `Origin` 頭。不要偽裝成瀏覽器。
- **使用字符串項目 ID。** ID 不限於數字。對於不託管在公共站點上的項目，請使用可識別的 ID，例如 `example.com/my-project`。
- **打開一個連接並保持它。** 使用事件驅動的 WebSocket，在事件發生時接收更新。不要循環打開和關閉連接來輪詢值。
- **不要刷屏更新。** 服務器會緩衝更新，可能重新排序，也可能丟棄一部分。每秒發送超過約 10 次更新沒有意義。
- **響應 ping。** 服務器會發送 WebSocket ping 幀；您的客戶端必須回覆 pong，否則連接會被斷開。
- **記錄關閉代碼和原始服務器消息。** 4xxx 關閉代碼在[協議參考](https://github.com/TurboWarp/cloud-server/blob/master/doc/protocol.md)中有文檔說明；記錄它們可以讓問題變得可診斷。

不要使用雲變量構建無審核的聊天室，也不要濫用該服務。
