RemixWarp 的外觀是可主題化的：淺色或深色編輯器、強調色、積木的顏色，以及您可以構建和分享的完全自定義主題。本頁說明每一個都在哪裡。

## 編輯器主題和強調色

整體的**淺色或深色**外觀和**強調色**應用於整個 RemixWarp（編輯器和社區站點），因此它們位於您的 RemixWarp 賬戶設置中，而不是編輯器自己的窗口中。打開[設置窗口](/editor/settings)，轉到**主題**頁面，然後按照**編輯我的 RemixWarp 設置**在站點上更改它們。

強調色分為純色、一組彩虹旗和更豐富的漸變強調色（如日落、海洋和極光）。您的選擇保存到賬戶，並在登錄時同步到您的設備。

## 積木顏色

編輯器的**主題**頁面設置積木本身的配色方案，與界面主題分開：

- **原始**：標準 Scratch 積木顏色。
- **高對比度**：更醒目、更高對比度的顏色，提高可讀性。
- **深色（測試版）**：較深的積木顏色以匹配深色編輯器。

要更精細地控制各個分類顏色，**在插件設置中自定義**會打開積木主題插件，每個分類的顏色都可以手動設置。

## 自定義主題

自定義主題將整體外觀（強調色、淺色或深色模式、積木顏色、壁紙和字體）捆綁在一個名稱下，這樣您可以在它們之間切換或分享它們。自定義主題管理器讓您：

- **從當前外觀創建**：將您設置的所有內容快照到命名主題中。
- **構建漸變主題**：在漸變構建器中設計漸變強調色（見下文）。
- **導入和導出**：從 JSON 文件加載主題，或將您的整個庫導出為一個文件。
- **瀏覽市場**：打開 WarpTheme 社區主題集合並將主題添加到您的庫中。

每個保存的主題都可以單獨應用、編輯、導出或刪除。

## 漸變構建器

漸變構建器為自定義主題設計漸變強調色：

- **色標**：沿預覽條拖動色標重新定位，選擇每個色標的顏色，並添加或移除色標（兩個到八個）。
- **方向**：用滑塊或八個預設箭頭之一設置漸變角度。
- **快速預設**：從現成的漸變開始。
- **主色**：從漸變派生的純色，用於 UI 強調。

**預覽**實時應用漸變，這樣您可以在保存前看到它，關閉預覽會恢復您之前的主題。

## 將主題與項目捆綁

項目可以攜帶自己的主題。保存時，RemixWarp 可以將您當前的主題存儲在項目中（通過[設置](/editor/settings)常規頁面上的**將設置存儲到項目中**，並勾選**將主題存儲到項目中**）。當有人在編輯器中打開該項目時，RemixWarp 會詢問是**應用**項目的主題還是**保留**他們自己的主題，並提供"不再詢問"選項。在項目的社區頁面上，存儲的主題會自動應用到播放器。
