菜單欄橫跨編輯器頂部。它包含下拉菜單（文件、編輯、工具、書籤）、設置按鈕、項目標題，右側是保存狀態和賬戶。本頁列出每個菜單和項目。

最左側的 **RemixWarp** 徽標是到主頁的鏈接。在窄窗口上，菜單摺疊到 **更多**（☰）按鈕後面；項目完全相同。

下面顯示的鍵盤快捷鍵在 Windows/Linux 上使用 `Ctrl`，在 macOS 上使用 `⌘`。完整列表在[鍵盤快捷鍵](/editor/shortcuts)中。

## 文件

- **新建** 創建全新項目。如果當前項目有未保存的更改，會先警告您。
- **新窗口**（僅桌面應用）打開第二個編輯器窗口。
- **立即保存**（`Ctrl+S`）保存到項目當前所在的位置。當您已登錄且項目屬於您時，這會上傳到 RemixWarp。請參閱[項目管理](/editor/project-management)。
- **另存為副本**（`Ctrl+Shift+S`）保存一個新的獨立副本。
- **改編** 基於當前項目開始一個新項目。
- **保存到 RemixWarp** / **改編到 RemixWarp**（登錄[Rotur 賬戶](/editor/project-management)後顯示）將項目上傳到您的賬戶。上傳本身從不發佈項目；分享是在網站上單獨進行的。
- **查看項目頁面** 打開此項目在社區站點上的頁面（項目存在於 RemixWarp 後顯示）。
- **從電腦加載**（`Ctrl+O`）從磁盤打開 `.sb3` 文件。
- **保存到（文件名）** 和 **另存為...** 將 `.sb3` 保存到您的電腦。在支持文件系統訪問 API 的瀏覽器上，您可以保存回同一文件；否則會正常下載。
- **打包項目**（`Ctrl+P`）在[打包器](/packager/overview)中打開當前項目。
- **提交到 Git...**、**推送到（遠程）**、**從（遠程）拉取** 在項目有[Git 倉庫](/editor/git)時出現。
- **還原點**（`Alt+R`）打開[還原點](/editor/restore-points)管理器；**創建還原點** 立即創建一個。
- **項目元數據** 顯示打開項目的作者、日期和內容。
- **暫停自動保存** / **恢復自動保存** 在自動保存開啟時出現，並帶有到下次自動保存的實時倒計時。

## 編輯

- **恢復角色 / 聲音 / 造型** 找回您最後刪除的內容（沒有可恢復內容時禁用）。
- **撤銷**（`Ctrl+Z`）和**重做**（`Ctrl+Shift+Z`）作用於積木[工作區](/editor/workspace)。
- **插件** 打開[插件設置](/editor/addons)。
- **桌面設置**（僅桌面應用）打開應用級選項。
- **更改用戶名** 設置報告給項目和雲變量的用戶名。
- **啟用 / 禁用雲變量** 為本次會話切換[雲變量](/advanced/cloud-variables)（在不可用時禁用）。
- **顯示教程** 重播入門演練。
- **幫助** 打開編輯器內的幫助窗口，一個可搜索的編輯器、積木和擴展參考。
- **originChats** 鏈接到 originChats 社區聊天。

## 模式

**模式**菜單僅在編輯器偶爾出現的愚人節狀態期間顯示。它提供**普通模式**和**貓咪模式**（貓主題積木）。它對項目運行沒有影響，並且一年中其他時間都關閉。

## 工具

- **Git** 打開[版本控制](/editor/git)窗口。
- **終端** 打開一個 shell 窗口。
- **實時協作** 打開[實時協作](/editor/collaboration)。
- **調試器**和**變量管理器** 在這些工具可用時出現，分別打開[調試器](/editor/debugger)和[變量管理器](/editor/variable-manager)。
- **添加擴展**（`Ctrl+.`）打開[擴展庫](/extensions/overview)以添加或導入擴展。
- **管理擴展**（`Ctrl+Alt+E`）列出項目中已加載的擴展。

## 書籤

書籤菜單管理[工作區書籤](/editor/bookmarks)：積木工作區中保存的相機位置，讓您可以立即跳回腳本。在這裡您可以添加、切換、重命名、刪除、導出、導入和清除書籤，並將它們組織到分類中。書籤與項目一起存儲。

快捷鍵：`Ctrl+Alt+T` 在當前位置添加書籤；`Ctrl+Alt+1` 到 `Ctrl+Alt+0` 切換到前十個書籤。

## 設置

**設置**按鈕打開[設置窗口](/editor/settings)：主題、語言、編譯器和運行時選項、[自定義 FPS](/advanced/custom-fps)、[自定義舞臺大小](/advanced/custom-stage-size)等。

## 右側

菜單欄右側的賬戶區域顯示：

- **保存狀態**，反映項目是否有未保存的更改。
- 會話進行中時的**實時協作**存在指示器。
- 到 RemixWarp 站點其餘部分的導航。
- 您的 **Rotur 賬戶**，或登錄提示。登錄啟用保存到 RemixWarp、分享以及設置的雲同步。

一個**項目標題**字段在您擁有該項目時位於中間。在項目頁面上，您可能還會看到瀏覽量計數器、**分享**按鈕、**改編**按鈕和**查看社區**按鈕，具體取決於項目和您是否已登錄。**反饋**鏈接始終可用。
