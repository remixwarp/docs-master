# 從 Scratch 遷移

RemixWarp 是功能更豐富的 Scratch 改版。您在 Scratch 中掌握的一切都以相同方式工作，因此遷移主要是打開項目並注意新增內容。

## 導入項目

RemixWarp 使用與 Scratch 相同的 `.sb3` 項目格式。

1. 在 Scratch 中，使用 **文件然後保存到電腦** 將項目下載為 `.sb3` 文件。
2. 在 RemixWarp 中，使用 **文件然後從電腦加載** 並選擇該文件。

您的角色、造型、聲音、變量和腳本都會完整保留。只要您沒有使用 RemixWarp 獨有的積木，也可以從 RemixWarp 保存回 `.sb3` 並在 Scratch 中再次打開。

## 相同之處

- 積木、分類、角色、造型、聲音和舞臺的行為與 Scratch 完全一致。請參閱[積木概覽](/blocks/overview)。
- 標準 Scratch 角色和背景素材庫仍然存在。
- 畫板編輯器和聲音編輯器的工作方式相同。請參閱[造型](/editor/costumes)和[聲音](/editor/sounds)。

## 不同之處

- **項目運行更快。** RemixWarp 會將積木編譯為 JavaScript。大多數項目只是運行更快；少數依賴 Scratch 精確時序的項目可能會有細微差異。如需對照解釋器檢查行為，請參閱[禁用編譯器](/advanced/disable-compiler)。
- **不再受限於 30 FPS 或 480x360 舞臺。** 請參閱[自定義 FPS](/advanced/custom-fps)和[自定義舞臺大小](/advanced/custom-stage-size)。
- **有更多積木和擴展**，包括畫筆、視頻與人臉感知、硬件等。請參閱[擴展概覽](/extensions/overview)。
- **可以使用插件和主題自定義編輯器。** 請參閱[插件](/editor/addons)和[主題](/editor/themes)。
- **有開發者工具**：調試器、還原點、git 和協作。請參閱[調試器](/editor/debugger)、[還原點](/editor/restore-points)、[Git](/editor/git)和[協作](/editor/collaboration)。

## 賬戶與分享

Scratch 賬戶和 RemixWarp 賬戶是相互獨立的。RemixWarp 有自己的社區平臺；您可以使用 **Rotur 賬戶**登錄來發布項目、關注他人和評論。構建、運行或保存項目到電腦不需要賬戶。保存與分享請參閱[項目管理](/editor/project-management)。

## 關於雲變量

RemixWarp 支持雲變量，但它們與 Scratch 的雲不互通。使用了 Scratch 雲變量的項目仍然可以加載；雲數據本身不會轉移。請參閱[雲變量](/advanced/cloud-variables)。
