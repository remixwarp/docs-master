# 從 TurboWarp 遷移

RemixWarp 構建在 TurboWarp 之上，因此如果您已經在使用 TurboWarp，編輯器看起來和使用起來幾乎完全相同。編譯器、任意幀率、自定義舞臺大小、插件、主題、還原點、打包器和高級設置都會保留，並按您的預期工作。項目使用相同的 `.sb3` 格式，TurboWarp 項目可以通過 **文件然後從電腦加載** 直接在 RemixWarp 中打開。

本頁重點介紹 RemixWarp 在 TurboWarp 基礎上新增的功能。

## 社區平臺與 Rotur 賬戶

最大的新增功能是完整的社區平臺。RemixWarp 編輯器和社區站點由同一個構建提供，因此發佈、個人資料和瀏覽項目都集成在同一個應用中。

- 使用 **Rotur 賬戶**登錄。在菜單欄中，您可以通過 **文件然後保存到 RemixWarp** 將項目直接保存到賬戶，然後打開其項目頁面。
- 登錄後，您會獲得個人資料、通知和社交功能（關注、評論和發帖）。
- 登錄狀態下，您的設置和主題會在設備間同步。

構建、運行、打包或本地保存項目不需要賬戶，這與 TurboWarp 完全一致。賬戶只增加社區功能。請參閱[項目管理](/editor/project-management)。

## 額外積木與擴展

RemixWarp 包含超出 TurboWarp 的額外積木和擴展。請在[擴展概覽](/extensions/overview)和[RemixWarp 額外積木](/blocks/mistwarp-extras)中瀏覽。

## Git 版本控制

RemixWarp 可以用 **git** 跟蹤項目。項目一旦存在倉庫，文件菜單就會為遠程倉庫提供提交、推送和拉取操作，因此您可以通過 git 託管來管理版本並與他人協作。請參閱[Git](/editor/git)。

## 實時協作

RemixWarp 增加了實時協作：多人可以同時編輯同一個項目，並看到彼此在編輯器中的存在。請參閱[協作](/editor/collaboration)。

## 調試器

RemixWarp 包含一個調試器，用於檢查運行中的項目、單步執行並觀察狀態，這超出了 TurboWarp 的標準工具。請參閱[調試器](/editor/debugger)。

## 主題與插件

TurboWarp 的插件和主題系統都存在並得到擴展。RemixWarp 提供自己的主題（包括自定義配色方案）和自己精選的插件。請參閱[主題](/editor/themes)和[插件](/editor/addons)。

## 相同之處

- 積木、編譯器和運行時行為。請參閱[積木概覽](/blocks/overview)。
- 高級設置，如[自定義 FPS](/advanced/custom-fps)、[自定義舞臺大小](/advanced/custom-stage-size)、[高質量畫筆](/advanced/high-quality-pen)、[插值](/advanced/interpolation)和[移除限制](/advanced/remove-limits)。
- 用於構建項目獨立版本的[打包器](/packager/overview)。
- URL 參數、嵌入和雲變量。請參閱[URL 參數](/advanced/url-parameters)、[嵌入](/advanced/embedding)和[雲變量](/advanced/cloud-variables)。
