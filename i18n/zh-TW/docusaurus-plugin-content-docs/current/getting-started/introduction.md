# 簡介

RemixWarp 是一個基於 TurboWarp 的 Scratch 修改版。如果您用過 Scratch，RemixWarp 會讓您感到熟悉：相同的積木、角色、造型和舞臺。在此基礎之上，它還增加了性能優化、自定義能力、開發者工具和社區平臺。

編輯器和社區站點是同一個應用。您可以打開 [remixwarp.pages.dev](https://remixwarp.pages.dev/) 立即開始創作，無需賬戶，也無需安裝任何東西。

## RemixWarp 新增了什麼

- **編譯器**：將您的積木編譯為 JavaScript，使項目比標準 Scratch 解釋器運行得更快。如需關閉它做對比，請參閱[禁用編譯器](/advanced/disable-compiler)。
- **任意幀率**和**自定義舞臺大小**，取代固定的 30 FPS 和 480x360。請參閱[自定義 FPS](/advanced/custom-fps)和[自定義舞臺大小](/advanced/custom-stage-size)。
- **插件**：可改變編輯器和播放器行為的小型可選功能。請參閱[插件](/editor/addons)。
- **主題**，包括深色模式和完全自定義的配色方案。請參閱[主題](/editor/themes)。
- **調試器**，用於單步執行和檢查運行中的項目。請參閱[調試器](/editor/debugger)。
- **還原點**和自動保存，避免丟失工作成果。請參閱[還原點](/editor/restore-points)。
- **Git 版本控制**和**實時協作**，便於長期管理和多人共同開發項目。請參閱[Git](/editor/git)和[協作](/editor/collaboration)。
- **打包器**，可將項目轉換為獨立應用或網頁。請參閱[打包器](/packager/overview)。
- **社區平臺**，支持賬戶、發佈項目、關注他人和評論。賬戶通過 Rotur 處理；關於社區功能如何運作，請參閱[從 TurboWarp 遷移](/getting-started/migrating-from-turbowarp)。

## 面向的讀者

RemixWarp 同時面向兩類讀者，本文檔也為他們而寫：

- 如果您**來自 Scratch**，您已經掌握的所有知識仍然適用。請從[從 Scratch 遷移](/getting-started/migrating-from-scratch)和[快速開始](/getting-started/quick-start)開始。
- 如果您是**高級用戶或開發者**，RemixWarp 通過 JavaScript、自定義擴展和文檔化的 API 開放了運行時。請參閱[JavaScript](/advanced/javascript)、[構建擴展](/building-extensions/introduction)和[API 參考](/api-reference/overview)。

## 默認角色

新的 RemixWarp 項目默認使用 RemixWarp 自己的角色 **Misty**，而不是 Scratch 貓。標準 Scratch 素材庫中的所有角色仍然可以在角色選擇器中找到。
