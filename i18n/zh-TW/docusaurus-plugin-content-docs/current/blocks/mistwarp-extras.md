RemixWarp 構建在 TurboWarp 之上，而 TurboWarp 構建在 Scratch 之上。一路走來，兩個項目都添加了標準 Scratch 沒有的積木。本頁將這些額外積木集中在一處。每一個都位於其正常分類中，並從該分類的頁面鏈接到。擴展積木（畫筆、音樂等）請參閱[擴展](/extensions/overview)；本頁只涉及內置額外積木。

其中一些積木默認顯示在積木區中；其他是來自導入項目或打開相應插件才會出現的兼容性或高級積木。它們在[編譯器](/advanced/disable-compiler)和解釋器中都以相同方式運行。

## 運動

- **面向 x: `0` y: `0`** 朝向特定座標，而不是菜單目標。
- **從 x: `0` y: `0` 面向 x: `0` y: `0`** 從一個座標朝向另一個座標。

請參閱[運動積木](/blocks/motion)。

## 控制

- **重複執行直到 `<條件>`** 在布爾值保持為真時循環（`重複執行直到` 的反義詞）。
- **對於 `10` 中的每個 `項目`** 循環設定次數，將變量設置為 1、2、3，依此類推。
- **全部同時** 在一幀內以無屏幕刷新讓步的方式運行其包裹的積木。為兼容舊項目而保留；[防卡死](/advanced/warp-timer)下的普通腳本行為相同。
- **切換 `表達式`** / **情況 `值`** / **默認** / **中斷** 構建 switch 語句。`切換` 通過匹配值選擇一個分支；普通的 `情況` 運行其分支然後停止；`默認` 在沒有匹配時運行；`中斷` 和 case 穿透控制讓一個 case 繼續到下一個。
- **計數器**（報告積木）、**計數器增加**、**將計數器設為 `0`** 是從 Scratch 2 繼承的簡單內置計數器，因此您無需建立變量即可計數。

請參閱[控制積木](/blocks/control)。

## 運算

- **`蘋果` 的第 `1` 到 `3` 個字符** 返回兩個位置之間的子字符串。
- **`蘋果` 中 `項目` 的位置** 返回子字符串的位置（不區分大小寫），如果未找到則為 0。
- **將 `蘋果` 中的 `a` 替換為 `-`** 替換子字符串的每次出現（不區分大小寫）。
- **`ab` 重複 `3` 次** 重複一個字符串。
- **將 `Apple` 轉為 `大寫` / `小寫`** 更改文本的大小寫。
- **修剪 `  蘋果  `** 移除周圍空白。
- **將 `5` 限制在 `0` 和 `10` 之間** 將數字限制在一個範圍內。
- **較小值** / **較大值** 返回操作數中較小或較大的值。
- **圓周率** 報告 3.14159...
- **換行符** 報告換行字符。

請參閱[運算積木](/blocks/operators)。

## 偵測

- **在線?** 報告設備是否有網絡連接（`navigator.onLine`）。
- **舞臺寬度** / **舞臺高度** 報告以像素為單位的舞臺大小。

請參閱[偵測積木](/blocks/sensing)。

## 變量和數據

- **`列表` 的 JSON 表示** 將列表報告為 JSON 數組字符串。

請參閱[變量和列表](/blocks/variables)。

## 自制積木

- **返回 `值`** 結束自定義積木並將值交還給調用者，讓自定義積木充當報告積木。
- **已編譯?** / **是 RemixWarp?** 是特殊的布爾參數報告積木名稱：`已編譯?` 在編譯器運行時報告真，`是 mistwarp?` 在這裡始終報告真。

請參閱[自制積木](/blocks/my-blocks)。
