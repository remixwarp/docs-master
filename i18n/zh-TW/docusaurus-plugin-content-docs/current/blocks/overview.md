積木是您拼在一起構建項目的拼圖塊。每個積木是一條指令；一疊積木就是一個腳本。RemixWarp 使用與 Scratch 相同的積木語言，因此您在 Scratch 中知道的一切在這裡都適用，並且它在此基礎上增加了一些額外積木（請參閱 [RemixWarp 額外積木](/blocks/mistwarp-extras)）。

## 積木形狀

積木的形狀告訴您它如何連接以及它的作用。

- **帽子積木**有圓形的頂部和平坦的底部。它們響應事件啟動腳本，例如 `當綠旗被點擊`。帽子積木上方不能放置任何積木。
- **堆疊積木**是矩形的，頂部有凹槽，底部有凸起。它們做一件事並將控制權傳遞給下面的積木，例如 `移動 10 步`。大多數積木都是這種形狀。
- **布爾積木**是尖頭的六邊形，報告 `真` 或 `假`，例如 `鼠標按下?`。它們插入其他積木的六邊形凹槽。
- **報告積木**是圓潤的橢圓形，報告一個值（數字或文本），例如 `x 座標` 或 `回答`。它們插入其他積木的圓形凹槽。
- **C 形積木**（也稱為包裹積木）包裹其他積木，例如 `重複執行 10` 或 `如果 ... 那麼`。您放進去的積木按照 C 形積木的規則運行。
- **終止積木**頂部有凹槽但底部平坦，因此後面不能再有積木。`停止全部` 和 `刪除此克隆體` 是終止積木。

## 積木區和分類

積木區位於[編輯器工作區](/editor/workspace)的左側。它按顏色編碼分類，點擊分類名稱（或其圓點）會將積木區滾動到該部分。內置分類有：

- [運動](/blocks/motion)（藍色）移動和旋轉角色。
- [外觀](/blocks/looks)（紫色）更改造型、大小、圖形效果和對話氣泡。
- [聲音](/blocks/sound)（品紅）播放聲音並設置音量。
- [事件](/blocks/events)（黃色）啟動腳本併發送廣播。
- [控制](/blocks/control)（金色）處理循環、條件、等待和克隆。
- [偵測](/blocks/sensing)（淺藍）讀取鼠標、鍵盤、計時器和其他角色。
- [運算](/blocks/operators)（綠色）進行數學、文本和邏輯運算。
- [變量](/blocks/variables)（橙色）存儲值和列表（數據）。
- [自制積木](/blocks/my-blocks)（粉紅/紅色）存放您自己定義的自制積木。

在這些下方，每個已加載的[擴展](/extensions/overview)（畫筆、音樂等）都會添加自己的分類。搜索和拖拽積木請參閱[積木區](/editor/blocks-palette)頁面。

## RemixWarp 和 TurboWarp 額外積木

RemixWarp 繼承了 TurboWarp 的附加積木並添加了自己的積木，因此出現了一些標準 Scratch 沒有的積木，分佈在幾個分類中：額外的運動、控制、運算、偵測和數據積木，以及一個用於自制積木的 `返回` 積木。這些按分類記錄，並彙總在[RemixWarp 額外積木](/blocks/mistwarp-extras)一頁中。
