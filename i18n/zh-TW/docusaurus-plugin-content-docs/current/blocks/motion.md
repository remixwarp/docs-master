---
title: 運動積木
sidebar_position: 2
---

運動積木在[舞臺](/editor/stage)上移動和旋轉角色。它們對舞臺本身沒有效果，因此選中舞臺時積木區會顯示精簡的積木集。位置使用 Scratch 座標：x 從左（負）到右（正），y 從下（負）到上（正），0,0 是中心。

## 移動

- **移動 `10` 步** 讓角色朝它面對的方向前進。
- **移到 x: `0` y: `0`** 將角色跳到精確位置。
- **移到 `隨機位置` / `鼠標指針` / 角色** 跳到目標、隨機點或鼠標處。
- **在 `1` 秒內滑行到 x: `0` y: `0`** 在給定時間內平滑移動到某個位置。
- **在 `1` 秒內滑行到 `隨機位置` / `鼠標指針` / 角色** 平滑滑動到目標。
- **將 x 座標增加 `10`** / **將 x 座標設為 `0`** 調整或設置水平位置。
- **將 y 座標增加 `10`** / **將 y 座標設為 `0`** 調整或設置垂直位置。

## 轉向與方向

- **右轉 `15` 度** / **左轉 `15` 度** 旋轉角色。
- **面向 `90` 方向** 朝向羅盤方向（90 是右，0 是上，-90 是左，180 是下）。
- **面向 `鼠標指針` / 角色** 朝向目標。
- **碰到邊緣就反彈** 當角色碰到舞臺邊緣時反轉方向。
- **將旋轉方式設為 `左右翻轉` / `不可旋轉` / `任意旋轉`** 控制角色如何視覺旋轉。

## 報告積木

- **x 座標** 報告當前的 x 座標。
- **y 座標** 報告當前的 y 座標。
- **方向** 報告當前以度為單位的朝向。

## RemixWarp 和 TurboWarp 額外積木

這些運動積木不在標準 Scratch 中：

- **面向 x: `0` y: `0`** 朝向特定座標，而不是從菜單中選擇目標。
- **從 x: `0` y: `0` 面向 x: `0` y: `0`** 從一個座標朝向另一個座標。

完整的額外積木列表請參閱[RemixWarp 額外積木](/blocks/mistwarp-extras)。
