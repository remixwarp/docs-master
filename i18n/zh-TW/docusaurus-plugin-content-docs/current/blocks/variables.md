title: 變量和列表
sidebar_position: 9
---

變量分類（內部稱為"數據"）包含兩種存儲方式：變量（每個保存一個值）和列表（按順序保存許多值）。您可以使用分類頂部的"建立一個變量"和"建立一個列表"按鈕創建變量和列表；RemixWarp 還有一個專門的[變量管理器](/editor/variable-manager)用於批量編輯。

變量或列表可以是**適用於所有角色**的（全局）或**僅適用於當前角色**的（限於一個角色及其克隆體）。

## 變量

- **`變量`**（報告積木）報告變量的當前值。在積木區勾選它的複選框會在[舞臺](/editor/stage)上顯示監視器。
- **將 `變量` 設為 `0`** 存儲一個值。
- **將 `變量` 增加 `1`** 向數字變量加上一個數字。
- **顯示變量 `變量`** / **隱藏變量 `變量`** 顯示或隱藏舞臺監視器。

## 列表

- **`列表`**（報告積木）報告列表的內容。
- **將 `東西` 加入 `列表`** 在末尾追加一項。
- **刪除 `列表` 的第 `1` 項** 按位置移除一項（菜單還提供 `最後一項` 和 `全部`）。
- **刪除 `列表` 的全部項目** 清空列表。
- **將 `東西` 插入 `列表` 的第 `1` 項** 在某個位置添加一項，將其餘項下移。
- **將 `列表` 的第 `1` 項替換為 `東西`** 覆蓋一項。
- **`列表` 的第 `1` 項** 返回某個位置的項目。
- **`東西` 在 `列表` 中的項目編號** 返回一項的位置，如果未找到則為 0。
- **`列表` 的項目數** 返回列表包含多少項。
- **`列表` 包含 `東西` ?** 報告列表是否包含某個項目。
- **顯示列表 `列表`** / **隱藏列表 `列表`** 在舞臺上顯示或隱藏列表監視器。

## RemixWarp 和 TurboWarp 額外積木

- **`列表` 的 JSON 表示**（`data_listjson`）將整個列表報告為 JSON 數組字符串，便於以文本形式保存或發送列表數據。
