侦测积木读取脚本周围的世界：碰撞、鼠标和键盘、计时器、日期以及其他角色的属性。

## 碰到与距离

- **碰到 `鼠标指针` / 边缘 / 角色 ?** 报告角色是否碰到目标。
- **碰到颜色 `[#颜色]` ?** 报告角色是否碰到屏幕上的某种颜色。
- **颜色 `[#颜色]` 碰到 `[#颜色]` ?** 报告角色上的一种颜色是否碰到另一种颜色。
- **到 `鼠标指针` / 角色的距离** 报告以像素为单位的距离。

## 询问与回答

- **询问 `你叫什么名字?` 并等待** 显示输入框并暂停直到用户回答。
- **回答** 报告最近一次的回答。

## 鼠标与键盘

- **鼠标按下?** 报告鼠标按钮是否被按住。
- **鼠标的 x 坐标** / **鼠标的 y 坐标** 报告指针的位置。
- **按下 `空格` 键?** 报告某个键是否被按住。
- **将拖动模式设为 `可拖动` / `不可拖动`** 控制播放者是否可以拖动此角色。

## 值与属性

- **响度** 报告麦克风输入电平（0 到 100）。
- **计时器** 报告自计时器上次重置以来的秒数；**计时器归零** 将其设置为零。
- **`背景编号` 属于 `舞台` / 角色的属性** 报告其他角色或舞台的属性（x、y、方向、造型、大小、音量、变量等）。
- **当前时间的 `年` / `月` / `日` / `星期` / `小时` / `分钟` / `秒`** 报告当前日期和时间的一部分。
- **自 2000 年以来的天数** 报告自 2000 年以来的天数（带小数）。
- **用户名** 在可用时报告已登录播放者的用户名。

## RemixWarp 和 TurboWarp 额外积木

- **在线?** 这个 `sensing_online` 布尔积木报告设备当前是否有网络连接（`navigator.onLine`）。
- **舞台宽度**（`sensing_stagewidth`）报告以像素为单位的舞台宽度（默认为 480，但[舞台大小](/user-guide/stage)可以更改）。
- **舞台高度**（`sensing_stageheight`）报告以像素为单位的舞台高度（默认为 360）。

还有一个由 `当 ... >` 帽子积木使用的 **响度 > `10`?** 风格布尔积木。

请参阅[RemixWarp 额外积木](/user-guide/mistwarp-extras)。
