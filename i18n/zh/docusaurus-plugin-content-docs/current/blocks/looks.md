外观积木更改角色（或[舞台](/user-guide/stage)）显示的内容：它的造型或背景、大小、图形效果、图层以及对话或思考气泡。选中舞台时，只显示与背景、效果和图层无关的积木。

## 对话与思考气泡

- **说 `你好!`** 显示一个一直保留到更改或清除的对话气泡。
- **说 `你好!` 持续 `2` 秒** 显示一个持续设定时间后消失的对话气泡。
- **思考 `嗯...`** 显示一个一直保留的思考气泡。
- **思考 `嗯...` 持续 `2` 秒** 显示一个持续设定时间的思考气泡。

说或思考空值会清除气泡。

## 显示与造型

- **显示** / **隐藏** 让角色可见或不可见。
- **换成 `造型` 造型** 按名称或编号更改造型。
- **下一个造型** 前进到下一个造型，在末尾循环。
- **造型 `编号` / `名称`** 报告当前造型的编号或名称。

## 背景（舞台）

- **换成 `背景` 背景** 更改舞台背景。菜单也接受 `下一个背景`、`上一个背景` 和 `随机背景`。
- **下一个背景** 前进到下一个背景。
- **换成 `背景` 背景并等待** 切换背景，然后等待所有 `当背景换成` 脚本完成。
- **背景 `编号` / `名称`** 报告当前背景的编号或名称。

## 大小与图形效果

- **将大小增加 `10`** / **将大小设为 `100` %** 调整或设置角色的大小。
- **大小** 报告当前大小的百分比。
- **将 `颜色` 效果增加 `25`** / **将 `颜色` 效果设为 `0`** 调整图形效果。效果包括颜色、鱼眼、漩涡、像素化、马赛克、亮度和虚像（透明度）。
- **清除图形特效** 将所有效果重置为零。

## 图层

- **移到最 `前面` / `后面`** 将角色移到最前面或最后面。
- **前移 / 后移 `1` 层** 将角色相对其当前位置移动若干层。
