title: 运动积木
sidebar_position: 2
---

运动积木在[舞台](/user-guide/stage)上移动和旋转角色。它们对舞台本身没有效果，因此选中舞台时积木区会显示精简的积木集。位置使用 Scratch 坐标：x 从左（负）到右（正），y 从下（负）到上（正），0,0 是中心。

## 移动

- **移动 `10` 步** 让角色朝它面对的方向前进。
- **移到 x: `0` y: `0`** 将角色跳到精确位置。
- **移到 `随机位置` / `鼠标指针` / 角色** 跳到目标、随机点或鼠标处。
- **在 `1` 秒内滑行到 x: `0` y: `0`** 在给定时间内平滑移动到某个位置。
- **在 `1` 秒内滑行到 `随机位置` / `鼠标指针` / 角色** 平滑滑动到目标。
- **将 x 坐标增加 `10`** / **将 x 坐标设为 `0`** 调整或设置水平位置。
- **将 y 坐标增加 `10`** / **将 y 坐标设为 `0`** 调整或设置垂直位置。

## 转向与方向

- **右转 `15` 度** / **左转 `15` 度** 旋转角色。
- **面向 `90` 方向** 朝向罗盘方向（90 是右，0 是上，-90 是左，180 是下）。
- **面向 `鼠标指针` / 角色** 朝向目标。
- **碰到边缘就反弹** 当角色碰到舞台边缘时反转方向。
- **将旋转方式设为 `左右翻转` / `不可旋转` / `任意旋转`** 控制角色如何视觉旋转。

## 报告积木

- **x 坐标** 报告当前的 x 坐标。
- **y 坐标** 报告当前的 y 坐标。
- **方向** 报告当前以度为单位的朝向。

## RemixWarp 和 TurboWarp 额外积木

这些运动积木不在标准 Scratch 中：

- **面向 x: `0` y: `0`** 朝向特定坐标，而不是从菜单中选择目标。
- **从 x: `0` y: `0` 面向 x: `0` y: `0`** 从一个坐标朝向另一个坐标。

完整的额外积木列表请参阅[RemixWarp 额外积木](/user-guide/mistwarp-extras)。
