# Makey Makey

**Makey Makey**扩展添加用于响应 Makey Makey 板的积木，这是一个小电路板（由 JoyLabz 制作），将日常导电物体（如香蕉或用铅笔画画）变成按键。它是内置的，并且与 Scratch 兼容。

从**添加扩展**加载它并选择 **Makey Makey**。

## 它如何工作

Makey Makey 通过 USB 插入您的电脑，并假装是键盘。当您通过触摸连接的对象完成电路时，它会发送一次按键。这些积木只是响应这些按键的更友好方式，因此不需要特殊驱动程序或蓝牙，只需要插上板子。

## 积木

### 当按下 `[键]` 键

```scratch
当按下 (空格 v) 键
```

一个在给定键被按下时运行的帽子积木。下拉框包括**空格**、四个**方向**键和字母键，与 Makey Makey 上的焊盘匹配。

### 当按顺序按下 `[序列]`

```scratch
当按顺序按下 (左 上 右 v)
```

一个只在按键序列以正确顺序被按下时运行的帽子积木，因此您可以构建连招和秘密代码。菜单提供预设序列（包括经典的上上-下下方向键模式）。

## 提示

- 测试这些并不严格需要 Makey Makey；因为它们响应普通的按键，同名的键盘键也会触发它们。
- *按顺序按下*积木对作弊代码和节奏输入很方便。
