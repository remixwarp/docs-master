# 画笔

**画笔**扩展让角色在舞台上绘制。角色移动时留下轨迹、盖图章或打印文本。它是内置的，可以离线工作，并且与 Scratch 兼容。RemixWarp 在 Scratch 积木的基础上添加了一些额外的画笔积木（三角形绘制和文本打印）。

从**添加扩展**加载它并选择**画笔**。

::::note
选中舞台时，积木区显示的画笔积木较少，因为一些画笔操作只对可移动的角色有意义。
::::

## 绘制积木

### 全部擦除

```scratch
全部擦除
```

清除画笔在舞台上绘制或盖章的所有内容。

### 图章

```scratch
图章
```

在角色位置将角色当前造型的副本绘制到舞台上。

### 落笔 / 抬笔

```scratch
落笔
抬笔
```

*落笔*开始让角色移动时留下轨迹。*抬笔*停止。

## 颜色与粗细

### 将画笔颜色设为 `[颜色]`

```scratch
将画笔颜色设为 [#ff0000]
```

使用颜色选择器设置画笔颜色。

### 将画笔的 `[参数]` 增加 `[值]` / 将画笔的 `[参数]` 设为 `[值]`

```scratch
将画笔的 (颜色 v) 增加 (10)
将画笔的 (亮度 v) 设为 (50)
```

调整画笔颜色的一个分量。下拉框提供**颜色**（色相）、**饱和度**、**亮度**和**透明度**。

### 将画笔粗细增加 `[粗细]` / 将画笔粗细设为 `[粗细]`

```scratch
将画笔粗细增加 (1)
将画笔粗细设为 (10)
```

控制画笔线条的粗细。

### 传统阴影和色相积木

```scratch
将画笔的阴影设为 (50)
将画笔的阴影增加 (10)
将画笔颜色设为 (0)
将画笔颜色增加 (10)
```

这些较旧的*阴影*和数字*色相*积木是为了兼容在新颜色参数积木存在之前制作的项目而保留的。在新项目中请优先使用*将画笔颜色设为*和*将画笔的 ... 设为*积木。

## 额外绘制积木（RemixWarp）

### 在 `[x0] [y0]`、`[x1] [y1]` 和 `[x2] [y2]` 之间绘制三角形

```scratch
在 (0) (0)、(50) (0) 和 (25) (50) 之间绘制三角形
```

使用当前画笔颜色在三个舞台坐标之间绘制（并填充）一个三角形。

### 打印文本

```scratch
将打印字体设为 [无衬线 v]
将打印字号设为 (20)
将打印字体颜色设为 [#000000]
将打印字体描边颜色设为 [#ffffff]
将打印字体描边宽度设为 (0)
将打印字体粗细设为 (400)
将打印字体斜体 (关闭 v)
在 x: (0) y: (0) 处打印 [你好]
```

这些积木配置一种字体，然后在给定位置将文本绘制到舞台上。描边设置为文本添加轮廓，*粗细*控制粗体程度。

## 提示

- 画笔绘制位于舞台的画笔层，与角色分开。*全部擦除*是清除它们的唯一方法（除了重新绘制）。
- 要在高分辨率下获得清晰的线条，请启用高质量画笔插件。请参阅[高质量画笔](/website/high-quality-pen)。
