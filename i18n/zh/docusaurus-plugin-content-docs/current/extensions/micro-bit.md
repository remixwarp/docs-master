# micro:bit

**micro:bit**扩展将项目连接到 BBC micro:bit，一个带按钮、运动侦测、LED 显示屏和输入引脚的小型可编程板。它是内置的，并且与 Scratch 兼容。

从**添加扩展**加载它并选择 **micro:bit**。

## 要求

micro:bit 通过蓝牙与 RemixWarp 通信，因此您需要：

- 一台带蓝牙和支持它的浏览器的电脑。
- **Scratch Link**（或 Scratch 应用）运行以将蓝牙桥接到浏览器。
- Scratch micro:bit HEX 固件刷写到板上。

添加扩展时，会出现连接窗口，让您配对板子。如果配对失败，请检查 Scratch Link 是否在运行以及固件是否已安装。

## 积木

### 当按下 `[按钮]` 按钮

一个在**A**、**B**或**任意**按钮被按下时运行的帽子积木。

### `[按钮]` 按钮被按下?

一个报告给定按钮当前是否被按住的布尔积木。

### 当 `[手势]`

一个在**移动**、**摇动**或**跳跃**等运动手势时运行的帽子积木。

### 显示 `[矩阵]`

在 5 乘 5 的 LED 显示屏上点亮一个图案。点击积木编辑哪些 LED 亮着。

### 显示文字 `[文本]`

在 LED 显示屏上滚动显示一条短消息。

### 清空显示

关闭每个 LED。

### 当倾斜 `[方向]` / 倾斜 `[方向]`? / 倾斜角度 `[方向]`

响应向**前**、**后**、**左**、**右**或**任意**方向倾斜板子，或将倾斜角度读取为数字。

### 当引脚 `[引脚]` 接通

一个在通过 micro:bit 引脚之一完成电路时运行的帽子积木，因此您可以连接自己的按钮。
