# RemixWarp 积木

**RemixWarp 积木**扩展（内部 id `tw`）添加一组标准 Scratch 没有的额外输入积木。它是内置的，可即时加载，并被标记为与 Scratch 不兼容，因此使用它的项目无法在 scratch.mit.edu 上运行。

从**添加扩展**加载它并选择**RemixWarp 积木**。

## 积木

### 最后按下的键

```scratch
(最后按下的键)
```

一个报告积木，返回用户最近按下的键的键名（例如 `空格`、`a`、`上箭头`）。对菜单、文本输入或让播放者重新绑定控制而不逐个检查每个键很有用。

### `[按钮]` 鼠标按钮按下?

```scratch
<(0) 鼠标按钮按下?>
```

一个布尔积木，报告特定鼠标按钮当前是否被按住。下拉框提供：

- **(0) 主按钮**（通常是左键）
- **(1) 中键**（滚轮按钮）
- **(2) 次按钮**（通常是右键）

下拉框接受报告积木，因此您可以在运行时计算按钮编号。这让您能检测右键和中键点击，而标准的 `鼠标按下?` 积木无法区分。

## 提示

- 这些积木读取与标准侦测积木相同的键盘和鼠标状态，因此它们在编辑器中和打包器中都能工作。
- 因为该扩展与 Scratch 不兼容，如果您计划将项目发布到 scratch.mit.edu，请避免使用。对于仅限 RemixWarp 的项目，可以放心依赖。
