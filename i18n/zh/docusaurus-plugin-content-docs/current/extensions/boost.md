# LEGO BOOST

**LEGO BOOST**扩展控制 LEGO BOOST 移动集线器，包括它的马达、颜色传感器和倾斜侦测。它是内置的，并且与 Scratch 兼容。

从**添加扩展**加载它并选择 **LEGO BOOST**。

## 要求

BOOST 通过蓝牙连接，因此您需要：

- 一台带蓝牙和支持的浏览器的电脑。
- **Scratch Link** 运行以将蓝牙桥接到浏览器。
- BOOST 移动集线器与您的电脑配对。

添加扩展会打开连接窗口以配对集线器。

## 积木

### 将马达 `[马达]` 开启 `[时长]` 秒

运行马达一段设定时间。

### 将马达 `[马达]` 开启 `[转数]` 转

运行马达一定转数。

### 将马达 `[马达]` 开启 / 关闭

启动或停止马达。

### 将马达 `[马达]` 速度设为 `[功率]` %

将马达速度从 0 设置为 100 百分比。

### 将马达 `[马达]` 方向设为 `[方向]`

将马达设置为**朝这个方向**、**朝那个方向**或**反转**运行。

### 马达 `[马达]` 位置

马达旋转位置的报告积木。

### 当看到 `[颜色]` 积木 / 看到 `[颜色]` 积木?

响应颜色传感器检测到彩色积木，作为帽子积木或布尔积木。

### 当倾斜 `[方向]` / 倾斜角度 `[方向]`

响应倾斜集线器，或读取它的倾斜角度。

### 将灯光颜色设为 `[色相]`

设置集线器内置灯光的颜色。
