title: 积木区

积木区是**代码**标签页左侧的列。它包含您可以使用的每个积木，按分类分组。将积木从积木区拖入[工作区](/user-guide/workspace)来将它添加到脚本。

## 分类

积木区分为多个分类，每个分类有自己的颜色。标准分类是：

- [运动](/user-guide/motion)、[外观](/user-guide/looks)、[声音](/user-guide/sound)
- [事件](/user-guide/events)、[控制](/user-guide/control)、[侦测](/user-guide/sensing)
- [运算](/user-guide/operators)、[变量](/user-guide/variables)和[自制积木](/user-guide/my-blocks)

最左侧一条彩色圆点是目录：点击一个圆点会将积木区直接滚动到该分类。每个分类的作用请参阅[积木概览](/user-guide/overview)。

**变量**分类还包含**建立一个变量**和**建立一个列表**按钮（请参阅[变量和列表](/user-guide/variables)），**自制积木**包含用于[自制积木](/user-guide/custom-blocks)的**建立一个积木**。

## 搜索

在积木区顶部的搜索框中输入，可以按名称跨所有分类过滤积木。当您大致知道积木叫什么时，这是找到它的最快方式。要跳转到项目中已有的特定积木、变量或自制积木，请改用[查找栏](/user-guide/find-bar)。

## 扩展添加分类

左下角的**添加扩展**按钮打开[扩展库](/extensions/overview)。添加扩展（例如[画笔](/extensions/pen)、[音乐](/extensions/music)或[文字朗读](/extensions/text-to-speech)）会在积木区底部附加一个新分类，包含该扩展的积木。某些扩展还会添加用于连接硬件的状态按钮。

RemixWarp 还提供标准 Scratch 之外的额外内置积木；请参阅[RemixWarp 额外积木](/user-guide/mistwarp-extras)。

## 调整大小与布局

您可以拖动积木区和工作区之间的边界来加宽或收窄积木区。几个[设置](/user-guide/settings)会更改积木区：

- **隐藏扩展按钮** 移除添加扩展的按钮。
- **仅标准兼容积木** 隐藏标准 Scratch 无法运行的积木（如返回积木、switch/case 积木和资源分类），当您希望项目保持与 scratch.mit.edu 兼容时很有用。
- **隐藏可扩展运算积木的箭头** 隐藏 `+` 和 `连接` 等积木上的加号/减号箭头。
