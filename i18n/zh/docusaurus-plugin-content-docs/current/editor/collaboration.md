实时协作让几个人同时实时编辑同一个项目。每个人都在自己的编辑器中工作，积木、角色、造型和声音的更改在所有人之间同步，实时光标显示谁在哪里工作。

::::warning
实时协作是一个 alpha 功能，仍处于早期开发阶段。在协作会话中编辑的项目可能被损坏或破坏。使用它时请保留自己的[还原点](/user-guide/restore-points)或保存的副本。
::::

## 开始或加入会话

打开**工具**菜单并选择**实时协作**。窗口显示您将以什么用户名出现，以及两个选项：

- **创建新房间**：主持一个房间。您会得到一个房间代码（以及可以分享的 URL），其他人用它加入。您是房间的**主持人**。
- **加入现有房间**：输入房间代码加入别人主持的房间。

分享房间通过发送它的 URL 完成，URL 携带一个 `?room=` 代码；打开该链接会自动加入房间。

## 会话期间

连接后，窗口列出房间中的每个人。每个人显示他们的头像和名称，在相关处显示**主持人**或**您**徽章，以及他们在做什么的实时描述，例如"正在编辑 Sprite1 中的代码"或"正在编辑舞台中的造型"。在工作区中，您会看到其他人的**光标**带名称标签，在他们移动时显示。

**复制房间 URL 以分享**复制邀请链接，**离开房间**断开您的连接。

## 主持人控制与隐私

创建房间的人是主持人，有额外控制：

- **踢出**任何其他参与者。
- 将房间设置为**公开**（任何有代码的人都可以加入）或**私有**（人们必须请求批准）。
- 在私有房间中，**批准或拒绝**每个待处理的加入请求。

当您加入私有房间时，您会等待主持人批准您，然后才能进入。

::::note
主持人转发每个人的编辑，这意味着主持人可以看到加入者的 IP 地址，而在您创建的房间中，加入者可以看到您的。窗口中的隐私声明在您主持或加入之前会说明这一点。
::::

## 协作与 git 的区别

实时协作用于在同一时刻一起编辑。对于异步团队合作（人们分别做更改，之后再合并），请改用[git 版本控制](/user-guide/git)。
