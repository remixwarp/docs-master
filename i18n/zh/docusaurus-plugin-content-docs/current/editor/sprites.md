角色是项目中的对象：角色、按钮、运动背景，任何有自己的脚本、造型和声音的东西。角色面板位于[舞台](/user-guide/stage)下方，列出每个角色，显示所选角色的属性，并让您添加新角色。

新的 RemixWarp 项目以一个名为 **Misty** 的角色开始。

## 角色列表

每个角色显示为一个显示缩略图和名称的图块。点击图块选择该角色；然后[代码](/user-guide/workspace)、[造型](/user-guide/costumes)和[声音](/user-guide/sounds)标签页编辑该角色。选中的角色会高亮。

右键单击角色图块会打开一个菜单，包含：

- **复制**：制作完整副本，包括脚本、造型和声音。
- **导出**：将角色以 `.sprite3` 文件保存到电脑，您可以将它导入另一个项目。
- **重命名**
- **删除**

您可以拖动图块重新排序。

## 角色属性

选中角色时，它的属性出现在列表上方：

- **角色**名称：重命名角色。
- **x** 和 **y**：它在[舞台](/user-guide/stage)上的位置。
- **显示** / 隐藏：角色是否可见（眼睛按钮）。
- **大小**：以百分比为单位的缩放，100 是造型的自然大小。
- **方向**：角色朝向的方式，用方向表盘设置。

在这里编辑这些与角色用[运动](/user-guide/motion)和[外观](/user-guide/looks)积木做一样；这只是起始值。

### 旋转方式

方向表盘还设置**旋转方式**，它控制角色如何转动：

- **任意旋转**：造型自由旋转以面对它的方向。
- **左右翻转**：造型只水平翻转，因此永远不会倒置。
- **不可旋转**：无论方向如何，造型永远不转动。

## 添加角色

圆形添加角色按钮（面板右下角）提供四种添加角色的方式：

- **选择一个角色**：从内置角色库中选择。
- **绘制**：创建空白角色并打开[画板编辑器](/user-guide/costumes)。
- **随机**：从库中添加随机角色。
- **上传角色**：从电脑加载图像或角色文件。接受的类型包括 `.svg`、`.png`、`.bmp`、`.jpg`、`.jpeg`、`.jfif`、`.webp`、`.gif` 和 Scratch 角色文件（`.sprite2`、`.sprite3`）。您可以一次选择多个文件。

## 舞台与背景

角色列表右侧是**舞台**图块。选择它可以让您编辑舞台的脚本、它的**背景**（造型标签页变成背景）以及它的声音。舞台不能移动，因此没有位置、大小或方向，但它可以有许多背景并在它们之间切换。
