RemixWarp 编辑器是您构建项目的地方。它完全在浏览器中运行（也可以在桌面应用中），并与社区站点来自同一构建。本页是编辑器窗口的地图：每个区域是什么以及在哪里阅读更多内容。

## 布局一览

编辑器分为几个固定区域：

- **菜单栏**横跨顶部：RemixWarp 徽标（返回主页的链接）、文件 / 编辑 / 工具 / 书签菜单、设置、项目标题，右侧是保存状态和账户。请参阅[菜单栏](/user-guide/menu-bar)。
- **舞台**在一边：运行中的项目、绿旗和停止按钮、舞台大小控件和全屏按钮。请参阅[舞台](/user-guide/stage)。
- **角色面板**在舞台下方：角色列表、所选角色的属性（位置、大小、方向、可见性）以及舞台/背景选择器。请参阅[角色](/user-guide/sprites)。
- **编辑区域**占据窗口的其余部分，由左上角的三个标签页控制：
  - **代码**：[积木区](/user-guide/blocks-palette)和[积木工作区](/user-guide/workspace)。
  - **造型**（选中舞台时是**背景**）：[画板编辑器](/user-guide/costumes)。
  - **声音**：[声音编辑器](/user-guide/sounds)。

三个标签页切换编辑区域为当前选中的角色或舞台显示的内容。舞台、角色面板和菜单栏在切换标签页时保持不变。

## 编辑器模式与播放器模式

同一个页面可以两种方式渲染。在**编辑器模式**下您会看到上面所有内容。在**播放器模式**下只显示舞台及其控件，这是访问者在共享项目页面或嵌入中看到的。社区项目页面将项目加载到嵌入的播放器中，而不是完整的编辑器。

## RemixWarp 编辑器有何不同

除了标准的 Scratch 布局，RemixWarp 编辑器还增加了：

- 一个将您的积木转换为 JavaScript 以提高速度的[编译器](/user-guide/overview)，以及[自定义 FPS](/website/custom-fps)、[自定义舞台大小](/website/custom-stage-size)和其他[高级设置](/user-guide/settings)。
- 重塑和重设编辑器样式的[插件](/user-guide/addons)和[自定义主题](/user-guide/themes)。
- 开发者工具：[调试器](/user-guide/debugger)、[变量管理器](/user-guide/variable-manager)、[还原点](/user-guide/restore-points)和自动保存、内置的[Git 版本控制](/user-guide/git)以及[实时协作](/user-guide/collaboration)。
- 用于在大型项目中导航的[查找栏](/user-guide/find-bar)和[工作区书签](/user-guide/bookmarks)。
