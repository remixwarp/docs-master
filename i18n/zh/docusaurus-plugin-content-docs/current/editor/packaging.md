**打包器**将项目变成独立应用：一个 HTML 文件、一个 zip，或 Windows、macOS、Linux 的原生应用，无需编辑器即可运行。它是一个独立的工具，编辑器可以直接将当前项目交给它。

## 打开打包器

**文件，打包项目**（`Ctrl+P`）打开[02Engine Packager](/packager/overview)，并加载好您打开的项目。您也可以单独访问 [packager.02engine.org](https://packager.02engine.org/) 并在那里加载 `.sb3`。

## 打包是做什么的

打包是您在 RemixWarp 站点之外分发完成项目的方式：

- 一个可以在任何地方托管或离线打开的单个 **HTML 文件**。
- 一个包含 HTML 及其资源的 **zip**。
- 用于桌面平台的原生**可执行文件**。

打包输出嵌入 RemixWarp 的运行时和编译器，因此打包项目以您选择的[设置](/user-guide/settings)以全速运行。您可以在打包器本身中自定义加载屏幕、控件、云变量行为等。

## 分享与打包的区别

这些是不同的事情：

- **分享**项目（从其[项目页面](/user-guide/project-management)）将其发布在社区站点上，人们可以在浏览器播放器中玩它。
- **打包**产生一个您自己拥有和分发的文件，不依赖 RemixWarp 站点。
