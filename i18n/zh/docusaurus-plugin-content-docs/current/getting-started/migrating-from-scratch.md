# 从 Scratch 迁移

RemixWarp 是功能更丰富的 Scratch 改版。您在 Scratch 中掌握的一切都以相同方式工作，因此迁移主要是打开项目并注意新增内容。

## 导入项目

RemixWarp 使用与 Scratch 相同的 `.sb3` 项目格式。

1. 在 Scratch 中，使用 **文件然后保存到电脑** 将项目下载为 `.sb3` 文件。
2. 在 RemixWarp 中，使用 **文件然后从电脑加载** 并选择该文件。

您的角色、造型、声音、变量和脚本都会完整保留。只要您没有使用 RemixWarp 独有的积木，也可以从 RemixWarp 保存回 `.sb3` 并在 Scratch 中再次打开。

## 相同之处

- 积木、分类、角色、造型、声音和舞台的行为与 Scratch 完全一致。请参阅[积木概览](/user-guide/overview)。
- 标准 Scratch 角色和背景素材库仍然存在。
- 画板编辑器和声音编辑器的工作方式相同。请参阅[造型](/user-guide/costumes)和[声音](/user-guide/sounds)。

## 不同之处

- **项目运行更快。** RemixWarp 会将积木编译为 JavaScript。大多数项目只是运行更快；少数依赖 Scratch 精确时序的项目可能会有细微差异。如需对照解释器检查行为，请参阅[禁用编译器](/website/disable-compiler)。
- **不再受限于 30 FPS 或 480x360 舞台。** 请参阅[自定义 FPS](/website/custom-fps)和[自定义舞台大小](/website/custom-stage-size)。
- **有更多积木和扩展**，包括画笔、视频与人脸感知、硬件等。请参阅[扩展概览](/extensions/overview)。
- **可以使用插件和主题自定义编辑器。** 请参阅[插件](/user-guide/addons)和[主题](/user-guide/themes)。
- **有开发者工具**：调试器、还原点、git 和协作。请参阅[调试器](/user-guide/debugger)、[还原点](/user-guide/restore-points)、[Git](/user-guide/git)和[协作](/user-guide/collaboration)。

## 账户与分享

Scratch 账户和 RemixWarp 账户是相互独立的。RemixWarp 有自己的社区平台；您可以使用 **Rotur 账户**登录来发布项目、关注他人和评论。构建、运行或保存项目到电脑不需要账户。保存与分享请参阅[项目管理](/user-guide/project-management)。

## 关于云变量

RemixWarp 支持云变量，但它们与 Scratch 的云不互通。使用了 Scratch 云变量的项目仍然可以加载；云数据本身不会转移。请参阅[云变量](/website/cloud-variables)。
