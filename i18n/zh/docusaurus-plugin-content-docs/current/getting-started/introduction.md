# 简介

RemixWarp 是一个基于 TurboWarp 的 Scratch 修改版。如果您用过 Scratch，RemixWarp 会让您感到熟悉：相同的积木、角色、造型和舞台。在此基础之上，它还增加了性能优化、自定义能力、开发者工具和社区平台。

编辑器和社区站点是同一个应用。您可以打开 [remixwarp.pages.dev](https://remixwarp.pages.dev/) 立即开始创作，无需账户，也无需安装任何东西。

## RemixWarp 新增了什么

- **编译器**：将您的积木编译为 JavaScript，使项目比标准 Scratch 解释器运行得更快。如需关闭它做对比，请参阅[禁用编译器](/website/disable-compiler)。
- **任意帧率**和**自定义舞台大小**，取代固定的 30 FPS 和 480x360。请参阅[自定义 FPS](/website/custom-fps)和[自定义舞台大小](/website/custom-stage-size)。
- **插件**：可改变编辑器和播放器行为的小型可选功能。请参阅[插件](/user-guide/addons)。
- **主题**，包括深色模式和完全自定义的配色方案。请参阅[主题](/user-guide/themes)。
- **调试器**，用于单步执行和检查运行中的项目。请参阅[调试器](/user-guide/debugger)。
- **还原点**和自动保存，避免丢失工作成果。请参阅[还原点](/user-guide/restore-points)。
- **Git 版本控制**和**实时协作**，便于长期管理和多人共同开发项目。请参阅[Git](/user-guide/git)和[协作](/user-guide/collaboration)。
- **打包器**，可将项目转换为独立应用或网页。请参阅[打包器](/packager/overview)。
- **社区平台**，支持账户、发布项目、关注他人和评论。账户通过 Rotur 处理；关于社区功能如何运作，请参阅[从 TurboWarp 迁移](/getting-started/migrating-from-turbowarp)。

## 面向的读者

RemixWarp 同时面向两类读者，本文档也为他们而写：

- 如果您**来自 Scratch**，您已经掌握的所有知识仍然适用。请从[从 Scratch 迁移](/getting-started/migrating-from-scratch)和[快速开始](/getting-started/quick-start)开始。
- 如果您是**高级用户或开发者**，RemixWarp 通过 JavaScript、自定义扩展和文档化的 API 开放了运行时。请参阅[JavaScript](/website/javascript)、[构建扩展](/extensions/introduction)和[API 参考](/api-reference/overview)。

## 默认角色

新的 RemixWarp 项目默认使用 RemixWarp 自己的角色 **Misty**，而不是 Scratch 猫。标准 Scratch 素材库中的所有角色仍然可以在角色选择器中找到。
