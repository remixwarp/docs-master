# 插值

插值通过在脚本帧之间的中间位置绘制角色，让运动看起来更平滑。它本质上是更高的视觉帧率，不改变脚本运行的速度，因此与[提高 FPS](/website/custom-fps)不同，它不会加速您的游戏或破坏时序。可以在[编辑器设置](/user-guide/settings)或通过 [`interpolate` URL 参数](/website/url-parameters) 启用。

## 何时不应使用

插值在以下情况下没有帮助，甚至可能损害性能：

- 3D 项目
- 光线追踪器
- 画笔项目（画笔无法插值）
- 已经卡顿的项目

## 权衡

- 它最多会增加约 1/30 秒的输入延迟，因为必须暂留一帧才能向其插值。
- 滚动平台游戏等复杂项目可能会出现轻微图形故障。

对于大多数非画笔的、移动角色的游戏来说，插值是保持 30 帧率的同时让运动感觉更流畅的廉价方法。
