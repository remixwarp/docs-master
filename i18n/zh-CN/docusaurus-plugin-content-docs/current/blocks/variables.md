变量分类（内部称为"数据"）包含两种存储方式：变量（每个保存一个值）和列表（按顺序保存许多值）。您可以使用分类顶部的"建立一个变量"和"建立一个列表"按钮创建变量和列表；RemixWarp 还有一个专门的[变量管理器](/editor/variable-manager)用于批量编辑。

变量或列表可以是**适用于所有角色**的（全局）或**仅适用于当前角色**的（限于一个角色及其克隆体）。

## 变量

- **`变量`**（报告积木）报告变量的当前值。在积木区勾选它的复选框会在[舞台](/editor/stage)上显示监视器。
- **将 `变量` 设为 `0`** 存储一个值。
- **将 `变量` 增加 `1`** 向数字变量加上一个数字。
- **显示变量 `变量`** / **隐藏变量 `变量`** 显示或隐藏舞台监视器。

## 列表

- **`列表`**（报告积木）报告列表的内容。
- **将 `东西` 加入 `列表`** 在末尾追加一项。
- **删除 `列表` 的第 `1` 项** 按位置移除一项（菜单还提供 `最后一项` 和 `全部`）。
- **删除 `列表` 的全部项目** 清空列表。
- **将 `东西` 插入 `列表` 的第 `1` 项** 在某个位置添加一项，将其余项下移。
- **将 `列表` 的第 `1` 项替换为 `东西`** 覆盖一项。
- **`列表` 的第 `1` 项** 返回某个位置的项目。
- **`东西` 在 `列表` 中的项目编号** 返回一项的位置，如果未找到则为 0。
- **`列表` 的项目数** 返回列表包含多少项。
- **`列表` 包含 `东西` ?** 报告列表是否包含某个项目。
- **显示列表 `列表`** / **隐藏列表 `列表`** 在舞台上显示或隐藏列表监视器。

## RemixWarp 和 TurboWarp 额外积木

- **`列表` 的 JSON 表示**（`data_listjson`）将整个列表报告为 JSON 数组字符串，便于以文本形式保存或发送列表数据。
