RemixWarp 构建在 TurboWarp 之上，而 TurboWarp 构建在 Scratch 之上。一路走来，两个项目都添加了标准 Scratch 没有的积木。本页将这些额外积木集中在一处。每一个都位于其正常分类中，并从该分类的页面链接到。扩展积木（画笔、音乐等）请参阅[扩展](/extensions/overview)；本页只涉及内置额外积木。

其中一些积木默认显示在积木区中；其他是来自导入项目或打开相应插件才会出现的兼容性或高级积木。它们在[编译器](/advanced/disable-compiler)和解释器中都以相同方式运行。

## 运动

- **面向 x: `0` y: `0`** 朝向特定坐标，而不是菜单目标。
- **从 x: `0` y: `0` 面向 x: `0` y: `0`** 从一个坐标朝向另一个坐标。

请参阅[运动积木](/blocks/motion)。

## 控制

- **重复执行直到 `<条件>`** 在布尔值保持为真时循环（`重复执行直到` 的反义词）。
- **对于 `10` 中的每个 `项目`** 循环设定次数，将变量设置为 1、2、3，依此类推。
- **全部同时** 在一帧内以无屏幕刷新让步的方式运行其包裹的积木。为兼容旧项目而保留；[防卡死](/advanced/warp-timer)下的普通脚本行为相同。
- **切换 `表达式`** / **情况 `值`** / **默认** / **中断** 构建 switch 语句。`切换` 通过匹配值选择一个分支；普通的 `情况` 运行其分支然后停止；`默认` 在没有匹配时运行；`中断` 和 case 穿透控制让一个 case 继续到下一个。
- **计数器**（报告积木）、**计数器增加**、**将计数器设为 `0`** 是从 Scratch 2 继承的简单内置计数器，因此您无需建立变量即可计数。

请参阅[控制积木](/blocks/control)。

## 运算

- **`苹果` 的第 `1` 到 `3` 个字符** 返回两个位置之间的子字符串。
- **`苹果` 中 `项目` 的位置** 返回子字符串的位置（不区分大小写），如果未找到则为 0。
- **将 `苹果` 中的 `a` 替换为 `-`** 替换子字符串的每次出现（不区分大小写）。
- **`ab` 重复 `3` 次** 重复一个字符串。
- **将 `Apple` 转为 `大写` / `小写`** 更改文本的大小写。
- **修剪 `  苹果  `** 移除周围空白。
- **将 `5` 限制在 `0` 和 `10` 之间** 将数字限制在一个范围内。
- **较小值** / **较大值** 返回操作数中较小或较大的值。
- **圆周率** 报告 3.14159...
- **换行符** 报告换行字符。

请参阅[运算积木](/blocks/operators)。

## 侦测

- **在线?** 报告设备是否有网络连接（`navigator.onLine`）。
- **舞台宽度** / **舞台高度** 报告以像素为单位的舞台大小。

请参阅[侦测积木](/blocks/sensing)。

## 变量和数据

- **`列表` 的 JSON 表示** 将列表报告为 JSON 数组字符串。

请参阅[变量和列表](/blocks/variables)。

## 自制积木

- **返回 `值`** 结束自定义积木并将值交还给调用者，让自定义积木充当报告积木。
- **已编译?** / **是 RemixWarp?** 是特殊的布尔参数报告积木名称：`已编译?` 在编译器运行时报告真，`是 mistwarp?` 在这里始终报告真。

请参阅[自制积木](/blocks/my-blocks)。
