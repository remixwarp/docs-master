积木是您拼在一起构建项目的拼图块。每个积木是一条指令；一叠积木就是一个脚本。RemixWarp 使用与 Scratch 相同的积木语言，因此您在 Scratch 中知道的一切在这里都适用，并且它在此基础上增加了一些额外积木（请参阅 [RemixWarp 额外积木](/blocks/mistwarp-extras)）。

## 积木形状

积木的形状告诉您它如何连接以及它的作用。

- **帽子积木**有圆形的顶部和平坦的底部。它们响应事件启动脚本，例如 `当绿旗被点击`。帽子积木上方不能放置任何积木。
- **堆叠积木**是矩形的，顶部有凹槽，底部有凸起。它们做一件事并将控制权传递给下面的积木，例如 `移动 10 步`。大多数积木都是这种形状。
- **布尔积木**是尖头的六边形，报告 `真` 或 `假`，例如 `鼠标按下?`。它们插入其他积木的六边形凹槽。
- **报告积木**是圆润的椭圆形，报告一个值（数字或文本），例如 `x 坐标` 或 `回答`。它们插入其他积木的圆形凹槽。
- **C 形积木**（也称为包裹积木）包裹其他积木，例如 `重复执行 10` 或 `如果 ... 那么`。您放进去的积木按照 C 形积木的规则运行。
- **终止积木**顶部有凹槽但底部平坦，因此后面不能再有积木。`停止全部` 和 `删除此克隆体` 是终止积木。

## 积木区和分类

积木区位于[编辑器工作区](/editor/workspace)的左侧。它按颜色编码分类，点击分类名称（或其圆点）会将积木区滚动到该部分。内置分类有：

- [运动](/blocks/motion)（蓝色）移动和旋转角色。
- [外观](/blocks/looks)（紫色）更改造型、大小、图形效果和对话气泡。
- [声音](/blocks/sound)（品红）播放声音并设置音量。
- [事件](/blocks/events)（黄色）启动脚本并发送广播。
- [控制](/blocks/control)（金色）处理循环、条件、等待和克隆。
- [侦测](/blocks/sensing)（浅蓝）读取鼠标、键盘、计时器和其他角色。
- [运算](/blocks/operators)（绿色）进行数学、文本和逻辑运算。
- [变量](/blocks/variables)（橙色）存储值和列表（数据）。
- [自制积木](/blocks/my-blocks)（粉红/红色）存放您自己定义的自制积木。

在这些下方，每个已加载的[扩展](/extensions/overview)（画笔、音乐等）都会添加自己的分类。搜索和拖拽积木请参阅[积木区](/editor/blocks-palette)页面。

## RemixWarp 和 TurboWarp 额外积木

RemixWarp 继承了 TurboWarp 的附加积木并添加了自己的积木，因此出现了一些标准 Scratch 没有的积木，分布在几个分类中：额外的运动、控制、运算、侦测和数据积木，以及一个用于自制积木的 `返回` 积木。这些按分类记录，并汇总在[RemixWarp 额外积木](/blocks/mistwarp-extras)一页中。
