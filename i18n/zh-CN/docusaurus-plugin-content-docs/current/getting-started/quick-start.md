# 快速开始

本页将从空白编辑器开始构建一个可运行的小项目。整个过程只需几分钟，并且假设您没有 RemixWarp 使用经验。如果您也没用过 Scratch，积木系统与 Scratch 相同；相关概念请参阅[从 Scratch 迁移](/getting-started/migrating-from-scratch)。

## 打开编辑器

前往 [remixwarp.pages.dev](https://remixwarp.pages.dev/)。会打开一个新项目，默认角色 **Misty** 已经在舞台上。本页上的所有操作都不需要账户。

## 添加代码

编辑器默认打开在**代码**标签页。[积木区](/editor/blocks-palette)在左侧，按类别分组；[工作区](/editor/workspace)在中间，用于摆放脚本。

1. 从**事件**类别中，将 `当绿旗被点击` 积木拖入工作区。这是一个帽子积木：项目运行时它会启动一个脚本。
2. 从**外观**中，将 `说 [你好！] (2) 秒` 积木拖出并吸附在帽子积木下方。
3. 从**运动**中，在下面拖入一个 `移动 (10) 步` 积木。
4. 从**控制**中，拖入一个 `重复执行` 积木，用它包裹住 `移动` 积木，让角色持续移动。

当积木的凹槽对齐时，它们就会吸附在一起。要拔出积木，请将其拖走；要删除积木，请将其拖回积木区。

## 运行它

右侧[舞台](/editor/stage)上方是绿旗和停止按钮。点击**绿旗**运行您的脚本；Misty 会问好并开始移动。点击**停止按钮**停止。按空格键也可以切换运行状态。

如果角色走出边缘，请从**运动**中添加一个 `碰到边缘就反弹` 积木，放在 `重复执行` 循环内。

## 改变外观

- **造型**标签页可以让您绘制或编辑角色的外观。请参阅[造型](/editor/costumes)。
- **声音**标签页用于管理音频。请参阅[声音](/editor/sounds)。
- 使用[角色区](/editor/sprites)右下角的角色按钮添加更多角色，并通过旁边的[舞台选择器](/editor/stage)更换背景。

## 保存

- **文件然后保存到电脑** 会下载一个 `.sb3` 文件。此操作无需账户，该文件也可以在 Scratch 和 TurboWarp 中打开。
- **文件然后从电脑加载** 稍后重新打开 `.sb3` 文件。
- 使用 Rotur 账户时，**文件然后保存到 RemixWarp** 会将项目发布到您的账户和社区。请参阅[项目管理](/editor/project-management)。

RemixWarp 还会在后台保存[还原点](/editor/restore-points)并自动保存，因此崩溃或误刷新不会丢失您的工作成果。
