RemixWarp 为常见编辑器操作提供键盘快捷键，并且它们可以重新绑定。显示为 `Ctrl` 的快捷键在 Windows 和 Linux 上使用 `Ctrl`，在 macOS 上使用 `⌘`（Command）。

## 默认快捷键

**文件**

| 操作 | 快捷键 |
| --- | --- |
| 保存 | `Ctrl+S` |
| 另存为副本 | `Ctrl+Shift+S` |
| 从电脑加载 | `Ctrl+O` |
| 打包项目 | `Ctrl+P` |
| 还原点 | `Ctrl+Shift+P` |

**编辑**

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Shift+Z` |
| 复制 | `Ctrl+C` |
| 粘贴 | `Ctrl+V` |
| 剪切 | `Ctrl+X` |

**视图**

| 操作 | 快捷键 |
| --- | --- |
| 设置 | `Ctrl+,` |
| 切换全屏 | `F11` |
| 切换背包 | `Ctrl+Shift+B` |
| 切换舞台全屏 | `Ctrl+Shift+F` |

**项目控制**

| 操作 | 快捷键 |
| --- | --- |
| 启动项目（绿旗） | `Ctrl+Enter` |
| 停止全部 | `Ctrl+Shift+Enter` |

**编辑器导航**

| 操作 | 快捷键 |
| --- | --- |
| 聚光搜索 | `Ctrl+K` |
| 代码标签页 | `Ctrl+1` |
| 造型标签页 | `Ctrl+2` |
| 声音标签页 | `Ctrl+3` |

**素材库**

| 操作 | 快捷键 |
| --- | --- |
| 角色库 | `Ctrl+Shift+A` |
| 造型库 | `Ctrl+Shift+C` |
| 声音库 | `Ctrl+Shift+M` |
| 扩展库 | `Ctrl+.` |
| 扩展管理器 | `Ctrl+Shift+E` |

**角色和窗口**

| 操作 | 快捷键 |
| --- | --- |
| 复制角色 | `Ctrl+Shift+D` |
| 删除角色 | `Ctrl+Shift+X` |
| 关闭窗口 | `Ctrl+Shift+K` |

一些功能有自己的按键，不在此管理器中，例如[查找栏](/editor/find-bar)（`Ctrl+F`）、[书签](/editor/bookmarks)（`Ctrl+Alt+T` 和 `Ctrl+Alt+1` 到 `0`）、[变量管理器](/editor/variable-manager)（`Ctrl+Shift+V`）和暂停（`Alt+X`）。

## 快捷键管理器

打开**设置**并转到**键盘快捷键**页面。它列出每个可重新绑定的快捷键，按分类分组，并带搜索框。

- 要更改一个，点击它的**铅笔**按钮，然后按新的组合键。`Escape` 取消。如果组合已被使用，管理器会告诉您哪个操作持有它并拒绝冲突。
- 更改过的快捷键显示**重置为默认值**按钮，一旦您有任何自定义绑定，**全部重置为默认值**按钮就会出现。

您的自定义绑定保存到浏览器中，并在登录时同步到您的账户，因此它们跟随您跨设备。
