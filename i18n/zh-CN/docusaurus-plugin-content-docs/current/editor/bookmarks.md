title: 工作区书签

工作区书签保存积木[工作区](/editor/workspace)中的一个位置，这样您可以立即跳回它。书签记录您正在看的位置（哪个角色、缩放级别和滚动位置），这比滚动查找脚本更快地在大型项目中移动。

## 书签菜单

书签通过[菜单栏](/editor/menu-bar)中的**书签**菜单管理。它包含一个搜索框、一个**添加当前位置**项目、书签列表，以及底部的导出 / 导入 / 全部清除。每个书签行显示其名称和保存日期，带有重命名（铅笔）和删除（垃圾桶）按钮。

## 添加和使用书签

- **添加**：选择**添加当前位置**，或按 `Ctrl+Alt+T`。这会在一个名称下保存当前角色、缩放和滚动位置。
- **切换**：点击书签返回恰好该视图。编辑器选择保存的角色并恢复其缩放和滚动偏移。
- **快捷键**：`Ctrl+Alt+1` 到 `Ctrl+Alt+9` 切换到前九个书签；`Ctrl+Alt+0` 切换到第十个。

## 分类

书签可以分组到**分类**中（默认为"常规"）。分类标题可以折叠和展开，这在项目有很多书签时保持列表可管理。

## 导出、导入和存储

- **导出**将您的书签下载为 JSON 文件；**导入**将文件合并回来，不会创建重复项。
- 书签**存储在项目内部**，因此它们随 `.sb3` 旅行，并在项目重新加载时重新出现。它们是按项目的。
