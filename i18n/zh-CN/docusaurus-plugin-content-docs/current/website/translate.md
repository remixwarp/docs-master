# 翻译

**翻译**扩展将文本翻译成其他语言，并告诉您观看者自己的语言。它是内置的，并且与 Scratch 兼容。翻译由 Google 提供。

从**添加扩展**加载它并选择**翻译**。

## 需要互联网

翻译由在线服务完成，因此此扩展每次翻译都需要互联网连接。离线时，翻译积木不会返回结果。

## 积木

### 将 `[文字]` 翻译为 `[语言]`

```scratch
(将 [你好] 翻译为 (西班牙语 v))
```

一个报告积木，返回给定文本翻译成所选语言的结果。从下拉框中选择目标语言。

### 语言

```scratch
(语言)
```

一个报告积木，返回观看者自己的语言（他们的浏览器或设备设置的语言）。将其与*将 ... 翻译为*结合，可以自动以运行项目的人使用的任何语言显示文本。

## 提示

- 机器翻译是近似值。简短、朴实的句子比习语或俚语翻译得更可靠。
- 使用*语言*报告积木作为*将 ... 翻译为*的目标，可以为每个观看者即时本地化您的项目。
