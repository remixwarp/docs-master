# 音乐

**音乐**扩展使用内置的合成声音集播放乐器音符和鼓声。它是内置的，可以离线工作，并且与 Scratch 兼容。它与 Scratch 中的音乐扩展相同。

从**添加扩展**加载它并选择**音乐**。

## 积木

### 击打 `[鼓]` 拍

```scratch
击打 (1 v) (0.25) 拍
```

播放 18 种打击乐声音之一（小军鼓、低音鼓、边击、碎音钹、开闭踩镲、铃鼓、拍手、响木、木鱼、牛铃、三角铁、邦戈鼓、康加鼓、卡巴萨、刮胡、颤音鞭、奎卡）持续给定的拍数，然后继续。

### 休止 `[拍数]` 拍

```scratch
休止 (0.25) 拍
```

不播放任何声音地等待给定的拍数。

### 弹奏音符 `[音符]` 拍

```scratch
弹奏音符 (60) (0.25) 拍
```

在当前乐器上播放一个音符（作为 MIDI 音符编号，用钢琴键选择器选择）持续给定的拍数。

### 将乐器设为 `[乐器]`

```scratch
将乐器设为 (1 v)
```

为此角色选择*弹奏音符*使用的乐器。有 21 种乐器，包括钢琴、电钢琴、风琴、吉他、电吉他、贝斯、拨弦、大提琴、长号、单簧管、萨克斯、长笛、木笛、巴松、合唱、颤音琴、八音盒、钢鼓、马林巴、合成主音和合成垫。

### 将速度设为 `[速度]`

```scratch
将速度设为 (60)
```

以每分钟节拍数设置速度。速度越高，音符和鼓播放得越快。

### 将速度增加 `[速度]`

```scratch
将速度增加 (20)
```

添加到当前速度。

### 速度

```scratch
(速度)
```

当前以每分钟节拍数为单位的速度的报告积木。

## 提示

- "拍"由速度定义，因此相同的*拍数*值根据速度以不同的真实时长播放。
- 乐器和速度是每角色的，因此不同角色可以同时播放不同的乐器。
- 不需要互联网或硬件。所有声音都在本地生成。
