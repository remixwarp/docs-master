# 结束

那是自定义扩展开发的核心。从这里开始，参考页面深入 API 表面的每个部分：

- [Scratch 对象 API](/extensions/apis/scratch-api)：完整的 `Scratch` 对象、积木工具和权限 API。
- [VM API](/extensions/apis/vm-api)：运行时、目标、线程和事件。
- [渲染器 API](/extensions/apis/renderer-api)：直接绘制皮肤和可绘制对象。
- [音频 API](/extensions/apis/audio-api)：音频引擎、声音播放器和效果。
- [实用 API](/extensions/apis/utility-apis)：`Scratch.Cast` 和相关辅助工具的详细内容。

如果您需要原生速度的积木，[编译扩展](/extensions/compiled/overview)部分展示了如何通过 RemixWarp 的编译器直接生成 JavaScript。

## 获取帮助和贡献

您可以在 [extensions.bilup.org](https://extensions.bilup.org) 浏览 RemixWarp 扩展画廊，并找到它的提交说明。

感谢您读到这里。
