# LEGO MINDSTORMS EV3

**LEGO MINDSTORMS EV3**扩展驱动 LEGO MINDSTORMS EV3 主机上的马达并读取传感器。它是内置的，并且与 Scratch 兼容。

从**添加扩展**加载它并选择 **LEGO MINDSTORMS EV3**。

## 要求

EV3 通过蓝牙连接，因此您需要：

- 一台带蓝牙和支持的浏览器的电脑。
- **Scratch Link** 运行以将蓝牙桥接到浏览器。
- EV3 主机与您的电脑配对。

添加扩展会打开连接窗口以配对主机。马达和传感器通过它们插入的端口寻址。

## 积木

### 马达 `[端口]` 朝这个方向转 `[时间]` 秒

在给定端口上按一个方向运行马达若干秒。

### 马达 `[端口]` 朝那个方向转 `[时间]` 秒

按相反方向运行马达若干秒。

### 马达 `[端口]` 功率设为 `[功率]` %

设置马达驱动的力度，从 0 到 100 百分比。

### 马达 `[端口]` 位置

马达当前旋转位置的报告积木。

### 当按钮 `[端口]` 被按下

一个在给定端口上的触摸传感器被按下时运行的帽子积木。

### 当距离 < `[距离]` / 当亮度 < `[距离]`

在距离或光传感器读数低于某个值时运行的帽子积木。

### 按钮 `[端口]` 被按下?

一个触摸传感器当前是否被按下的布尔积木。

### 距离 / 亮度

当前距离和光传感器读数的报告积木。

### 蜂鸣音符 `[音符]` `[时间]` 秒

在主机扬声器上播放音调。
