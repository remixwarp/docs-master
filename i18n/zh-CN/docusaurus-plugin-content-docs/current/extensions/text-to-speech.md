# 文字朗读

**文字朗读**扩展让您的项目用选定的声音和语言大声朗读文本。它是内置的，并且与 Scratch 兼容。语音由 Amazon Web Services 生成。

从**添加扩展**加载它并选择**文字朗读**。

## 需要互联网

语音由在线服务合成，因此此扩展每次朗读都需要互联网连接。离线时不会产生声音。

## 积木

### 朗读 `[文字]`

```scratch
朗读 [你好]
```

大声朗读给定文本，并在继续脚本之前等待语音结束。

### 将声音设为 `[声音]`

```scratch
将声音设为 (女低音 v)
```

选择声音。选项有**女低音**、**男高音**、**吱吱声**、**巨人**和**小猫**。声音按角色记住。

### 将语言设为 `[语言]`

```scratch
将语言设为 (中文 v)
```

设置用于发音文本的语言。将其与您说的词语的语言匹配，让它们听起来正确。

## 提示

- 因为*朗读*等待音频结束，连续的*朗读*积木会一个接一个地读。
- 在用另一种语言朗读文本之前设置语言；相同的词语根据所选语言的发音差别很大。
