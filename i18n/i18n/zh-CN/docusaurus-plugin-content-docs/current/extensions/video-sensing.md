# 视频侦测

**视频侦测**扩展在舞台上显示您的网络摄像头并测量其中的运动，因此角色可以对您挥手或在摄像头前移动做出反应。它是内置的，并且与 Scratch 兼容。

从**添加扩展**加载它并选择**视频侦测**。

## 需要摄像头

视频第一次打开时，您的浏览器会请求使用网络摄像头的权限。视频侦测检测摄像头图像中运动的大小和方向；它不识别面部或物体。面部检测请参阅[人脸感知](/extensions/face-sensing)。

## 积木

### 当视频运动大于 `[阈值]`

```scratch
当视频运动大于 (10)
```

一个帽子积木，每当测量的运动超过给定阈值时运行其脚本。

### 视频 `[属性]` 在 `[对象]` 上

```scratch
(视频 (运动 v) 在 (角色 v) 上)
```

当前视频读数的报告积木。**属性**是**运动**（多少运动）或**方向**（朝哪个方向移动）。**对象**是**角色**（只在此角色上方的区域）或**舞台**（整个舞台）。

### 将视频 `[状态]`

```scratch
将视频 (开启 v)
```

将摄像头画面**开启**、**关闭**或**开启翻转**（左右镜像，通常感觉更自然）。

### 将视频透明度设为 `[透明度]`

```scratch
将视频透明度设为 (50)
```

设置摄像头图像在舞台上的透明程度，从 0（不透明）到 100（不可见）。即使视频完全透明，运动侦测仍然有效。

## 提示

- 运动是在视频帧之间测量的，因此静态场景读数接近零，快速运动读数高。
- 使用*在角色上*让每个角色只响应自己区域的运动，例如通过挥手"按"的按钮。
