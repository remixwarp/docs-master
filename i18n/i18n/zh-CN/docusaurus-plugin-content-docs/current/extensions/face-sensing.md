# 人脸感知

**人脸感知**扩展检测网络摄像头中的面部，并报告其特征的位置，因此角色可以跟随您的鼻子、坐在您的头上，或在您倾斜时做出反应。它是一个远程扩展，不与编辑器捆绑。

从**添加扩展**加载它并选择**人脸感知**。

## 远程加载，需要摄像头

人脸感知不与编辑器捆绑。您第一次加载它时，RemixWarp 会从远程 URL 下载它，因此您需要互联网连接来加载它（一旦加载并保存，它会随项目重新加载）。与视频侦测一样，它需要网络摄像头权限才能运行。

## 积木

该扩展提供几组积木：

- **面部检测**：一个在*检测到面部时*运行的帽子积木，以及一个布尔积木*检测到面部?*，让您可以在脚本的任何地方检查面部。
- **面部大小**：一个*面部大小*报告积木，报告检测到面部的大小，以及一个将角色大小设置为与面部匹配的命令。
- **面部倾斜**：一个*面部倾斜*报告积木、一个在*面部向左或向右倾斜时*运行的帽子积木，以及一个让角色朝向倾斜方向的命令。
- **特征位置**：报告面部部位位置的报告积木，包括两眼之间、每只眼睛、鼻子、嘴、每只耳朵和头顶，以及一个将角色移动到这些部位中任何一个的*移到*命令。

确切的积木措辞来自扩展本身；在编辑器中打开它查看完整列表。

## 提示

- 一次只跟踪一个面部，因此这最适合单个人在光线合理的情况下面对摄像头。
- 将*移到*面部部位与角色造型结合，制作跟随您面部的帽子、眼镜或面具。
- 如果检测无法启动，通常是摄像头权限或光线问题，而不是项目 bug。
