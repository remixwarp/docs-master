# renderer.getBoundsForBubble()

获取与某个可绘制对象关联的文本气泡的包围盒。

## 语法

```javascript
renderer.getBoundsForBubble(drawableID)
```

## 参数

### drawableID
**类型：** `number`

拥有该气泡的可绘制对象 ID。

## 返回值

**类型：** `object`

包围盒对象（left、right、top、bottom、width、height）。
