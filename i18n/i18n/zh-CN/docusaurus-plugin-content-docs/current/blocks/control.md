title: 控制积木

控制积木决定其他积木何时以及多久运行一次：循环、条件、等待、停止和克隆。其中几个是包裹里面积木的 C 形积木。

## 等待

- **等待 `1` 秒** 将脚本暂停一段时间。
- **等待直到 `<条件>`** 暂停直到布尔值变为真。

## 循环

- **重复执行 `10`** 运行包裹的积木设定次数。
- **重复执行** 无限运行包裹的积木（终止积木，后面不能有内容）。
- **重复执行直到 `<条件>`** 运行包裹的积木直到布尔值变为真。

## 条件

- **如果 `<条件>` 那么** 只在布尔值为真时运行包裹的积木。
- **如果 `<条件>` 那么 ... 否则** 为真时运行第一个分支，为假时运行第二个分支。

## 停止与克隆

- **停止 `全部` / `这个脚本` / `该角色的其他脚本`** 停止脚本。`全部` 停止整个项目。
- **当作为克隆体启动时**（帽子积木）在此角色的克隆体被创建时运行。
- **克隆 `自己` / 角色** 制作角色的运行副本。
- **删除此克隆体** 删除运行此脚本的克隆体（终止积木）。

## RemixWarp 和 TurboWarp 额外积木

这些控制积木不在标准 Scratch 的积木区中：

- **重复执行直到 `<条件>`** 在布尔值保持为真时运行包裹的积木（与 `重复执行直到` 相反，原文如此，指 while 循环）。
- **对于 `10` 中的每个 `项目`** 每个计数运行一次包裹的积木，将变量设置为 1、2、3，依此类推。
- **全部同时** 在一帧内不进行任何屏幕刷新让步地运行包裹的积木。主要为了兼容性而保留；[防卡死](/advanced/warp-timer)下的普通脚本行为相同。
- **切换 `表达式`**、**情况 `值`**、**默认** 和 **中断** 构建一个 switch 语句：匹配的 `情况` 分支运行，普通情况在下一个情况处停止（除非您添加 `中断` 行为，否则不穿透）。详细信息请参阅[RemixWarp 额外积木](/blocks/mistwarp-extras)。
- **计数器**、**计数器增加** 和 **将计数器设为 `0`** 是从 Scratch 2 继承的轻量内置计数器（报告、堆叠和重置）。它们避免为简单计数而需要变量。
