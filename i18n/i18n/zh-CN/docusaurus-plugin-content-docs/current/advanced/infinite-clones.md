# 无限克隆

Scratch 将项目同时存在的克隆限制为 300 个。此选项移除该上限，让您可以创建任意数量的克隆。可以在[编辑器设置](/editor/settings)中启用，或通过 [`clones` URL 参数](/advanced/url-parameters)（`clones=1000`）设置明确上限。

::::caution
有些项目依赖 Scratch 在超过限制后拒绝创建更多克隆。当限制被移除时，这些项目可能会出现异常。创建非常大量的克隆也会使项目变慢或耗尽内存。
::::
