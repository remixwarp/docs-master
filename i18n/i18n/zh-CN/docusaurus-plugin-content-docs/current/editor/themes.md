RemixWarp 的外观是可主题化的：浅色或深色编辑器、强调色、积木的颜色，以及您可以构建和分享的完全自定义主题。本页说明每一个都在哪里。

## 编辑器主题和强调色

整体的**浅色或深色**外观和**强调色**应用于整个 RemixWarp（编辑器和社区站点），因此它们位于您的 RemixWarp 账户设置中，而不是编辑器自己的窗口中。打开[设置窗口](/editor/settings)，转到**主题**页面，然后按照**编辑我的 RemixWarp 设置**在站点上更改它们。

强调色分为纯色、一组彩虹旗和更丰富的渐变强调色（如日落、海洋和极光）。您的选择保存到账户，并在登录时同步到您的设备。

## 积木颜色

编辑器的**主题**页面设置积木本身的配色方案，与界面主题分开：

- **原始**：标准 Scratch 积木颜色。
- **高对比度**：更醒目、更高对比度的颜色，提高可读性。
- **深色（测试版）**：较深的积木颜色以匹配深色编辑器。

要更精细地控制各个分类颜色，**在插件设置中自定义**会打开积木主题插件，每个分类的颜色都可以手动设置。

## 自定义主题

自定义主题将整体外观（强调色、浅色或深色模式、积木颜色、壁纸和字体）捆绑在一个名称下，这样您可以在它们之间切换或分享它们。自定义主题管理器让您：

- **从当前外观创建**：将您设置的所有内容快照到命名主题中。
- **构建渐变主题**：在渐变构建器中设计渐变强调色（见下文）。
- **导入和导出**：从 JSON 文件加载主题，或将您的整个库导出为一个文件。
- **浏览市场**：打开 WarpTheme 社区主题集合并将主题添加到您的库中。

每个保存的主题都可以单独应用、编辑、导出或删除。

## 渐变构建器

渐变构建器为自定义主题设计渐变强调色：

- **色标**：沿预览条拖动色标重新定位，选择每个色标的颜色，并添加或移除色标（两个到八个）。
- **方向**：用滑块或八个预设箭头之一设置渐变角度。
- **快速预设**：从现成的渐变开始。
- **主色**：从渐变派生的纯色，用于 UI 强调。

**预览**实时应用渐变，这样您可以在保存前看到它，关闭预览会恢复您之前的主题。

## 将主题与项目捆绑

项目可以携带自己的主题。保存时，RemixWarp 可以将您当前的主题存储在项目中（通过[设置](/editor/settings)常规页面上的**将设置存储到项目中**，并勾选**将主题存储到项目中**）。当有人在编辑器中打开该项目时，RemixWarp 会询问是**应用**项目的主题还是**保留**他们自己的主题，并提供"不再询问"选项。在项目的社区页面上，存储的主题会自动应用到播放器。
