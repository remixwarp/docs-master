# 变量和列表

变量存储单个值（一个数字或一段文本）。列表按顺序存储许多值。两者都位于积木区的**变量**分类中，并且都用该分类顶部的按钮创建。

## 建立一个变量

1. 打开[积木区](/editor/blocks-palette)中的**变量**分类。
2. 点击**建立一个变量**。
3. 输入名称并选择作用域（见下文）。
4. 点击**确定**。

您的新变量会出现在积木区中，带有 `设`、`增`、`显示`和`隐藏`积木，以及一个可以放入任何输入的报告积木。

列表以相同方式工作：改为点击**建立一个列表**。列表带有添加、删除、插入、替换和读取项目以及检查其长度和内容的积木。

## 作用域：所有角色 vs 当前角色

建立变量或列表时，您选择两个作用域之一：

- **适用于所有角色**（全局）：每个角色和舞台共享同一个变量。从一个角色更改它，到处都会更改。用于分数或游戏状态等整个项目都关心的内容。
- **仅适用于当前角色**（局部）：变量属于当前选中的角色。其他角色看不到它，角色的每个克隆体都有自己的私有副本。用于健康值或速度等每个角色的数据。

舞台只能持有全局变量，因为它没有克隆体，也没有"局部"可以归属。

::::note
两个角色可以各自拥有同名局部变量而不冲突，因为它们确实是独立的变量。局部变量和全局变量也可以同名；在它的角色内，局部变量优先。
::::

## 舞台上的监视器

每个变量和列表都有一个**监视器**，即显示在[舞台](/editor/stage)上的小读数。通过勾选积木区中变量旁边的复选框来切换它，或使用 `显示变量` / `隐藏变量` 积木。

- 将监视器拖到舞台上的任何位置来重新定位它。
- 右键单击变量监视器可在普通读数、大读数和可以拖动以实时更改值的滑块之间切换。
- 右键单击列表监视器可调整大小或导出/导入其内容。

监视器与项目一起保存，因此它们的位置和样式随之旅行。

## 高级说明

- 变量和列表值存储为 JavaScript 字符串和数字。[编译器](/advanced/disable-compiler)直接读写它们，因此大列表很快，但非常大的列表仍然消耗内存和保存时间。
- 列表比较默认不区分大小写。[设置](/editor/settings)中的**区分大小写的列表**选项使 `"a"` 和 `"A"` 成为不同的值，这可以以标准兼容性为代价加快列表密集型项目。
- 要一次查看或批量编辑所有变量和列表，请使用[变量管理器](/editor/variable-manager)。
