# 插值

插值通過在腳本幀之間的中間位置繪製角色，讓運動看起來更平滑。它本質上是更高的視覺幀率，不改變腳本運行的速度，因此與[提高 FPS](/website/custom-fps)不同，它不會加速您的遊戲或破壞時序。可以在[編輯器設置](/user-guide/settings)或通過 [`interpolate` URL 參數](/website/url-parameters) 啟用。

## 何時不應使用

插值在以下情況下沒有幫助，甚至可能損害性能：

- 3D 項目
- 光線追蹤器
- 畫筆項目（畫筆無法插值）
- 已經卡頓的項目

## 權衡

- 它最多會增加約 1/30 秒的輸入延遲，因為必須暫留一幀才能向其插值。
- 滾動平臺遊戲等複雜項目可能會出現輕微圖形故障。

對於大多數非畫筆的、移動角色的遊戲來說，插值是保持 30 幀率的同時讓運動感覺更流暢的廉價方法。
