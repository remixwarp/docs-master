title: 外觀積木

外觀積木更改角色（或[舞臺](/editor/stage)）顯示的內容：它的造型或背景、大小、圖形效果、圖層以及對話或思考氣泡。選中舞臺時，只顯示與背景、效果和圖層無關的積木。

## 對話與思考氣泡

- **說 `你好!`** 顯示一個一直保留到更改或清除的對話氣泡。
- **說 `你好!` 持續 `2` 秒** 顯示一個持續設定時間後消失的對話氣泡。
- **思考 `嗯...`** 顯示一個一直保留的思考氣泡。
- **思考 `嗯...` 持續 `2` 秒** 顯示一個持續設定時間的思考氣泡。

說或思考空值會清除氣泡。

## 顯示與造型

- **顯示** / **隱藏** 讓角色可見或不可見。
- **換成 `造型` 造型** 按名稱或編號更改造型。
- **下一個造型** 前進到下一個造型，在末尾循環。
- **造型 `編號` / `名稱`** 報告當前造型的編號或名稱。

## 背景（舞臺）

- **換成 `背景` 背景** 更改舞臺背景。菜單也接受 `下一個背景`、`上一個背景` 和 `隨機背景`。
- **下一個背景** 前進到下一個背景。
- **換成 `背景` 背景並等待** 切換背景，然後等待所有 `當背景換成` 腳本完成。
- **背景 `編號` / `名稱`** 報告當前背景的編號或名稱。

## 大小與圖形效果

- **將大小增加 `10`** / **將大小設為 `100` %** 調整或設置角色的大小。
- **大小** 報告當前大小的百分比。
- **將 `顏色` 效果增加 `25`** / **將 `顏色` 效果設為 `0`** 調整圖形效果。效果包括顏色、魚眼、漩渦、像素化、馬賽克、亮度和虛像（透明度）。
- **清除圖形特效** 將所有效果重置為零。

## 圖層

- **移到最 `前面` / `後面`** 將角色移到最前面或最後面。
- **前移 / 後移 `1` 層** 將角色相對其當前位置移動若干層。
