運算積木進行數學運算、比較值、組合邏輯並操作文本。它們都是報告積木或布爾積木，因此它們插入其他積木的凹槽，而不是獨立存在。

## 數學

- **`( )` + `( )`**、**`-`**、**`*`**、**`/`** 是加法、減法、乘法和除法。
- **在 `1` 和 `10` 之間取隨機數** 返回範圍內的隨機數。如果兩個輸入都是整數，則返回整數，否則返回小數。
- **`( )` 除以 `( )` 的餘數** 返回餘數（使用向下取整除法，因此結果與除數符號一致）。
- **`( )` 四捨五入** 四捨五入到最近的整數。
- **`絕對值` / `向下取整` / `向上取整` / `平方根` / `sin` / `cos` / `tan` / `asin` / `acos` / `atan` / `ln` / `log` / `e^` / `10^` 的 `( )`** 應用從菜單中選擇的數學函數。

## 比較與邏輯

- **`( )` < `( )`**、**`( )` = `( )`**、**`( )` > `( )`** 比較兩個值。
- **`< >` 且 `< >`**、**`< >` 或 `< >`** 組合兩個布爾值。
- **不成立 `< >`** 反轉布爾值。

## 文本

- **連接 `蘋果` 和 `香蕉`** 將兩個值連接成一個字符串。
- **`蘋果` 的第 `1` 個字符** 按位置返回單個字符。
- **`蘋果` 的字符數** 返回字符數。
- **`蘋果` 包含 `a` ?** 報告文本是否包含子字符串（不區分大小寫）。

## RemixWarp 和 TurboWarp 額外積木

這些運算積木不在標準 Scratch 中：

- **`蘋果` 的第 `1` 到 `3` 個字符** 返回兩個位置之間的子字符串。
- **`蘋果` 中 `項目` 的位置**（`index_of`）返回子字符串的位置，如果未找到則為 0（不區分大小寫）。
- **將 `蘋果` 中的 `a` 替換為 `-`** 替換子字符串的每次出現（不區分大小寫）。
- **`ab` 重複 `3` 次** 將字符串重複若干次。
- **將 `Apple` 轉為 `大寫` / `小寫`** 更改文本的大小寫。
- **修剪 `  蘋果  `** 移除前導和尾隨空白。
- **將 `5` 限制在 `0` 和 `10` 之間** 將數字限制在一個範圍內。
- **`( )` 和 `( )` 的較小值** / **較大值** 返回較小或較大的值（這些接受兩個以上的操作數）。
- **圓周率** 報告常數 3.14159...，方便進行圓相關數學計算。
- **換行符** 報告換行字符，用於構建多行字符串。
