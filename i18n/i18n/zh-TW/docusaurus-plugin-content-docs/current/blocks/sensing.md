偵測積木讀取腳本週圍的世界：碰撞、鼠標和鍵盤、計時器、日期以及其他角色的屬性。

## 碰到與距離

- **碰到 `鼠標指針` / 邊緣 / 角色 ?** 報告角色是否碰到目標。
- **碰到顏色 `[#顏色]` ?** 報告角色是否碰到屏幕上的某種顏色。
- **顏色 `[#顏色]` 碰到 `[#顏色]` ?** 報告角色上的一種顏色是否碰到另一種顏色。
- **到 `鼠標指針` / 角色的距離** 報告以像素為單位的距離。

## 詢問與回答

- **詢問 `你叫什麼名字?` 並等待** 顯示輸入框並暫停直到用戶回答。
- **回答** 報告最近一次的回答。

## 鼠標與鍵盤

- **鼠標按下?** 報告鼠標按鈕是否被按住。
- **鼠標的 x 座標** / **鼠標的 y 座標** 報告指針的位置。
- **按下 `空格` 鍵?** 報告某個鍵是否被按住。
- **將拖動模式設為 `可拖動` / `不可拖動`** 控制播放者是否可以拖動此角色。

## 值與屬性

- **響度** 報告麥克風輸入電平（0 到 100）。
- **計時器** 報告自計時器上次重置以來的秒數；**計時器歸零** 將其設置為零。
- **`背景編號` 屬於 `舞臺` / 角色的屬性** 報告其他角色或舞臺的屬性（x、y、方向、造型、大小、音量、變量等）。
- **當前時間的 `年` / `月` / `日` / `星期` / `小時` / `分鐘` / `秒`** 報告當前日期和時間的一部分。
- **自 2000 年以來的天數** 報告自 2000 年以來的天數（帶小數）。
- **用戶名** 在可用時報告已登錄播放者的用戶名。

## RemixWarp 和 TurboWarp 額外積木

- **在線?** 這個 `sensing_online` 布爾積木報告設備當前是否有網絡連接（`navigator.onLine`）。
- **舞臺寬度**（`sensing_stagewidth`）報告以像素為單位的舞臺寬度（默認為 480，但[舞臺大小](/editor/stage)可以更改）。
- **舞臺高度**（`sensing_stageheight`）報告以像素為單位的舞臺高度（默認為 360）。

還有一個由 `當 ... >` 帽子積木使用的 **響度 > `10`?** 風格布爾積木。

請參閱[RemixWarp 額外積木](/blocks/mistwarp-extras)。
