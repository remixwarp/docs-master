# 快速開始

本頁將從空白編輯器開始構建一個可運行的小項目。整個過程只需幾分鐘，並且假設您沒有 RemixWarp 使用經驗。如果您也沒用過 Scratch，積木系統與 Scratch 相同；相關概念請參閱[從 Scratch 遷移](/getting-started/migrating-from-scratch)。

## 打開編輯器

前往 [remixwarp.pages.dev](https://remixwarp.pages.dev/)。會打開一個新項目，默認角色 **Misty** 已經在舞臺上。本頁上的所有操作都不需要賬戶。

## 添加代碼

編輯器默認打開在**代碼**標籤頁。[積木區](/editor/blocks-palette)在左側，按類別分組；[工作區](/editor/workspace)在中間，用於擺放腳本。

1. 從**事件**類別中，將 `當綠旗被點擊` 積木拖入工作區。這是一個帽子積木：項目運行時它會啟動一個腳本。
2. 從**外觀**中，將 `說 [你好！] (2) 秒` 積木拖出並吸附在帽子積木下方。
3. 從**運動**中，在下面拖入一個 `移動 (10) 步` 積木。
4. 從**控制**中，拖入一個 `重複執行` 積木，用它包裹住 `移動` 積木，讓角色持續移動。

當積木的凹槽對齊時，它們就會吸附在一起。要拔出積木，請將其拖走；要刪除積木，請將其拖回積木區。

## 運行它

右側[舞臺](/editor/stage)上方是綠旗和停止按鈕。點擊**綠旗**運行您的腳本；Misty 會問好並開始移動。點擊**停止按鈕**停止。按空格鍵也可以切換運行狀態。

如果角色走出邊緣，請從**運動**中添加一個 `碰到邊緣就反彈` 積木，放在 `重複執行` 循環內。

## 改變外觀

- **造型**標籤頁可以讓您繪製或編輯角色的外觀。請參閱[造型](/editor/costumes)。
- **聲音**標籤頁用於管理音頻。請參閱[聲音](/editor/sounds)。
- 使用[角色區](/editor/sprites)右下角的角色按鈕添加更多角色，並通過旁邊的[舞臺選擇器](/editor/stage)更換背景。

## 保存

- **文件然後保存到電腦** 會下載一個 `.sb3` 文件。此操作無需賬戶，該文件也可以在 Scratch 和 TurboWarp 中打開。
- **文件然後從電腦加載** 稍後重新打開 `.sb3` 文件。
- 使用 Rotur 賬戶時，**文件然後保存到 RemixWarp** 會將項目發佈到您的賬戶和社區。請參閱[項目管理](/editor/project-management)。

RemixWarp 還會在後臺保存[還原點](/editor/restore-points)並自動保存，因此崩潰或誤刷新不會丟失您的工作成果。
