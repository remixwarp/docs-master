# 安裝

RemixWarp 是免費開源的。沒有任何需要購買的東西，網頁版也無需安裝。您可以通過三種方式使用它：在瀏覽器中、作為桌面應用，或者作為單個項目的打包獨立構建。

## 在網頁上使用

在任何現代瀏覽器中打開 [remixwarp.pages.dev](https://remixwarp.pages.dev/)。編輯器加載完成後即可立即開始創作。創建、編輯、保存到電腦或打開 `.sb3` 文件都不需要賬戶。

當您想要以下功能時，可以使用 **Rotur 賬戶**登錄：

- 將項目發佈到 RemixWarp 社區，
- 關注他人、評論並顯示在您的個人資料中，
- 在設備之間同步設置和主題。

這些功能以後再做也可以；開始創作並不需要賬戶。

### 保存工作成果

沒有賬戶時，使用 **文件然後保存到電腦** 下載 `.sb3` 文件，使用 **文件然後從電腦加載** 重新打開。有賬戶時，**文件然後保存到 RemixWarp** 會將項目發佈到社區平臺並保存在您的賬戶中。完整的保存與分享流程請參閱[項目管理](/editor/project-management)。

## 桌面應用

RemixWarp 有一個桌面應用，可以在自己的窗口中運行相同的編輯器，而不是瀏覽器標籤頁。桌面版增加了網頁無法提供的便利功能，例如多編輯器窗口和原生文件處理。請從 [github.com/RemixWarp/desktop/releases](https://github.com/RemixWarp/desktop/releases) 下載當前版本。

桌面應用是可選的。所有核心功能在網頁版中都可用。

## 打包項目

[RemixWarp 打包器](https://packager.02engine.org/) 可以將單個項目轉換為可分發獨立程序：HTML 文件、zip 壓縮包或原生可執行文件，所有這些都不需要編輯器即可運行。這不是 RemixWarp 本身的安裝程序；而是用於製作項目的構建工具。

您可以通過 **文件然後打包項目**（Ctrl+P）將當前項目直接發送到打包器。更多選項（如離線構建、自定義舞臺縮放和商業用途）請參閱[打包器概覽](/packager/overview)。

## 瀏覽器支持

RemixWarp 支持當前版本的 Chrome、Edge、Firefox 和 Safari。它需要 JavaScript、WebGL 和 Web Audio API，這些瀏覽器默認都提供。如果舞臺無法渲染，請檢查瀏覽器設置中是否啟用了硬件加速和 WebGL。
