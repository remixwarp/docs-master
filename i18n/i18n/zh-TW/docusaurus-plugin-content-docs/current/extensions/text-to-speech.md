# 文字朗讀

**文字朗讀**擴展讓您的項目用選定的聲音和語言大聲朗讀文本。它是內置的，並且與 Scratch 兼容。語音由 Amazon Web Services 生成。

從**添加擴展**加載它並選擇**文字朗讀**。

## 需要互聯網

語音由在線服務合成，因此此擴展每次朗讀都需要互聯網連接。離線時不會產生聲音。

## 積木

### 朗讀 `[文字]`

```scratch
朗讀 [你好]
```

大聲朗讀給定文本，並在繼續腳本之前等待語音結束。

### 將聲音設為 `[聲音]`

```scratch
將聲音設為 (女低音 v)
```

選擇聲音。選項有**女低音**、**男高音**、**吱吱聲**、**巨人**和**小貓**。聲音按角色記住。

### 將語言設為 `[語言]`

```scratch
將語言設為 (中文 v)
```

設置用於發音文本的語言。將其與您說的詞語的語言匹配，讓它們聽起來正確。

## 提示

- 因為*朗讀*等待音頻結束，連續的*朗讀*積木會一個接一個地讀。
- 在用另一種語言朗讀文本之前設置語言；相同的詞語根據所選語言的發音差別很大。
