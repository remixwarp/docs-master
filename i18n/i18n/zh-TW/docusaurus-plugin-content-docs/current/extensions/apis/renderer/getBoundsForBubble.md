# renderer.getBoundsForBubble()

獲取與某個可繪製對象關聯的文本氣泡的包圍盒。

## 語法

```javascript
renderer.getBoundsForBubble(drawableID)
```

## 參數

### drawableID
**類型：** `number`

擁有該氣泡的可繪製對象 ID。

## 返回值

**類型：** `object`

包圍盒對象（left、right、top、bottom、width、height）。
