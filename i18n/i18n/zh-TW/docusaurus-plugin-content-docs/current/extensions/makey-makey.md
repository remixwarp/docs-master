# Makey Makey

**Makey Makey**擴展添加用於響應 Makey Makey 板的積木，這是一個小電路板（由 JoyLabz 製作），將日常導電物體（如香蕉或用鉛筆畫畫）變成按鍵。它是內置的，並且與 Scratch 兼容。

從**添加擴展**加載它並選擇 **Makey Makey**。

## 它如何工作

Makey Makey 通過 USB 插入您的電腦，並假裝是鍵盤。當您通過觸摸連接的對象完成電路時，它會發送一次按鍵。這些積木只是響應這些按鍵的更友好方式，因此不需要特殊驅動程序或藍牙，只需要插上板子。

## 積木

### 當按下 `[鍵]` 鍵

```scratch
當按下 (空格 v) 鍵
```

一個在給定鍵被按下時運行的帽子積木。下拉框包括**空格**、四個**方向**鍵和字母鍵，與 Makey Makey 上的焊盤匹配。

### 當按順序按下 `[序列]`

```scratch
當按順序按下 (左 上 右 v)
```

一個只在按鍵序列以正確順序被按下時運行的帽子積木，因此您可以構建連招和秘密代碼。菜單提供預設序列（包括經典的上上-下下方向鍵模式）。

## 提示

- 測試這些並不嚴格需要 Makey Makey；因為它們響應普通的按鍵，同名的鍵盤鍵也會觸發它們。
- *按順序按下*積木對作弊代碼和節奏輸入很方便。
