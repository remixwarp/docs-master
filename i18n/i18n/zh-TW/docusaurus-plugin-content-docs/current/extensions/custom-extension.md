# 自定義擴展

**自定義擴展**庫項目加載不在內置列表中的擴展。您可以將其指向 URL、上傳本地文件，或直接粘貼 JavaScript 源碼。

打開**添加擴展**並選擇**自定義擴展**。

## 加載方式

- **從 URL** - 粘貼以 `.js` 結尾的鏈接。這是從 [extensions.bilup.org](https://extensions.bilup.org/) 等畫廊加載社區擴展的方式。URL 會與項目一起保存，因此項目打開時會從同一 URL 重新加載擴展。
- **從文件** - 從電腦上傳 `.js` 文件。擴展的代碼嵌入在項目中。
- **從文本** - 直接粘貼 JavaScript 源碼。

## 沙箱與非沙箱

加載自定義擴展時，您選擇以沙箱還是非沙箱方式運行它。

- **沙箱**擴展在隔離的 worker 中運行。它們可以添加積木並進行計算，但不能直接接觸頁面、VM 內部或渲染器。這是更安全的默認選項，對大多數擴展來說足夠了。
- **非沙箱**擴展以對運行時、渲染器和頁面的完全訪問權限運行。它們可以做沙箱擴展做不到的事情（讀取角色狀態的自定義報告積木、直接渲染等），但它們也可以做頁面能做的任何事情。

作為用戶，除非擴展特別需要非沙箱訪問，否則優先使用沙箱。如果您在編寫擴展，[沙箱](/building-extensions/sandbox)和[非沙箱](/building-extensions/unsandboxed)詳細說明了權衡。

## 安全提示

::::warning
加載自定義擴展會運行別人的代碼。只從您信任的來源加載擴展。
::::

在來自 URL 或文件的擴展運行之前，RemixWarp 會顯示提示，告訴您它來自哪裡，並讓您取消。非沙箱擴展承擔更多風險，因為它們不被隔離。如果您不是有意加載擴展，或者您不識別來源，請取消。惡意擴展可以讀取您的項目、發出網絡請求並干擾頁面。

## 加載後

自定義擴展積木像內置擴展一樣作為自己的分類出現。擴展與項目一起保存，因此您不必每次會話都重新加載它，其他打開項目的人會得到相同的積木（從同一 URL 加載，或者如果您從文件或文本加載則嵌入）。
