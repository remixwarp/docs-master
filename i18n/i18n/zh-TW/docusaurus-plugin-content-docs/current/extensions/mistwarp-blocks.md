# RemixWarp 積木

**RemixWarp 積木**擴展（內部 id `tw`）添加一組標準 Scratch 沒有的額外輸入積木。它是內置的，可即時加載，並被標記為與 Scratch 不兼容，因此使用它的項目無法在 scratch.mit.edu 上運行。

從**添加擴展**加載它並選擇**RemixWarp 積木**。

## 積木

### 最後按下的鍵

```scratch
(最後按下的鍵)
```

一個報告積木，返回用戶最近按下的鍵的鍵名（例如 `空格`、`a`、`上箭頭`）。對菜單、文本輸入或讓播放者重新綁定控制而不逐個檢查每個鍵很有用。

### `[按鈕]` 鼠標按鈕按下?

```scratch
<(0) 鼠標按鈕按下?>
```

一個布爾積木，報告特定鼠標按鈕當前是否被按住。下拉框提供：

- **(0) 主按鈕**（通常是左鍵）
- **(1) 中鍵**（滾輪按鈕）
- **(2) 次按鈕**（通常是右鍵）

下拉框接受報告積木，因此您可以在運行時計算按鈕編號。這讓您能檢測右鍵和中鍵點擊，而標準的 `鼠標按下?` 積木無法區分。

## 提示

- 這些積木讀取與標準偵測積木相同的鍵盤和鼠標狀態，因此它們在編輯器中和打包器中都能工作。
- 因為該擴展與 Scratch 不兼容，如果您計劃將項目發佈到 scratch.mit.edu，請避免使用。對於僅限 RemixWarp 的項目，可以放心依賴。
