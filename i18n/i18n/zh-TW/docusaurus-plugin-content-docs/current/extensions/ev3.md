# LEGO MINDSTORMS EV3

**LEGO MINDSTORMS EV3**擴展驅動 LEGO MINDSTORMS EV3 主機上的馬達並讀取傳感器。它是內置的，並且與 Scratch 兼容。

從**添加擴展**加載它並選擇 **LEGO MINDSTORMS EV3**。

## 要求

EV3 通過藍牙連接，因此您需要：

- 一臺帶藍牙和支持的瀏覽器的電腦。
- **Scratch Link** 運行以將藍牙橋接到瀏覽器。
- EV3 主機與您的電腦配對。

添加擴展會打開連接窗口以配對主機。馬達和傳感器通過它們插入的端口尋址。

## 積木

### 馬達 `[端口]` 朝這個方向轉 `[時間]` 秒

在給定端口上按一個方向運行馬達若干秒。

### 馬達 `[端口]` 朝那個方向轉 `[時間]` 秒

按相反方向運行馬達若干秒。

### 馬達 `[端口]` 功率設為 `[功率]` %

設置馬達驅動的力度，從 0 到 100 百分比。

### 馬達 `[端口]` 位置

馬達當前旋轉位置的報告積木。

### 當按鈕 `[端口]` 被按下

一個在給定端口上的觸摸傳感器被按下時運行的帽子積木。

### 當距離 < `[距離]` / 當亮度 < `[距離]`

在距離或光傳感器讀數低於某個值時運行的帽子積木。

### 按鈕 `[端口]` 被按下?

一個觸摸傳感器當前是否被按下的布爾積木。

### 距離 / 亮度

當前距離和光傳感器讀數的報告積木。

### 蜂鳴音符 `[音符]` `[時間]` 秒

在主機揚聲器上播放音調。
