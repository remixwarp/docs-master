# 畫筆

**畫筆**擴展讓角色在舞臺上繪製。角色移動時留下軌跡、蓋圖章或打印文本。它是內置的，可以離線工作，並且與 Scratch 兼容。RemixWarp 在 Scratch 積木的基礎上添加了一些額外的畫筆積木（三角形繪製和文本打印）。

從**添加擴展**加載它並選擇**畫筆**。

::::note
選中舞臺時，積木區顯示的畫筆積木較少，因為一些畫筆操作只對可移動的角色有意義。
::::

## 繪製積木

### 全部擦除

```scratch
全部擦除
```

清除畫筆在舞臺上繪製或蓋章的所有內容。

### 圖章

```scratch
圖章
```

在角色位置將角色當前造型的副本繪製到舞臺上。

### 落筆 / 抬筆

```scratch
落筆
抬筆
```

*落筆*開始讓角色移動時留下軌跡。*抬筆*停止。

## 顏色與粗細

### 將畫筆顏色設為 `[顏色]`

```scratch
將畫筆顏色設為 [#ff0000]
```

使用顏色選擇器設置畫筆顏色。

### 將畫筆的 `[參數]` 增加 `[值]` / 將畫筆的 `[參數]` 設為 `[值]`

```scratch
將畫筆的 (顏色 v) 增加 (10)
將畫筆的 (亮度 v) 設為 (50)
```

調整畫筆顏色的一個分量。下拉框提供**顏色**（色相）、**飽和度**、**亮度**和**透明度**。

### 將畫筆粗細增加 `[粗細]` / 將畫筆粗細設為 `[粗細]`

```scratch
將畫筆粗細增加 (1)
將畫筆粗細設為 (10)
```

控制畫筆線條的粗細。

### 傳統陰影和色相積木

```scratch
將畫筆的陰影設為 (50)
將畫筆的陰影增加 (10)
將畫筆顏色設為 (0)
將畫筆顏色增加 (10)
```

這些較舊的*陰影*和數字*色相*積木是為了兼容在新顏色參數積木存在之前製作的項目而保留的。在新項目中請優先使用*將畫筆顏色設為*和*將畫筆的 ... 設為*積木。

## 額外繪製積木（RemixWarp）

### 在 `[x0] [y0]`、`[x1] [y1]` 和 `[x2] [y2]` 之間繪製三角形

```scratch
在 (0) (0)、(50) (0) 和 (25) (50) 之間繪製三角形
```

使用當前畫筆顏色在三個舞臺座標之間繪製（並填充）一個三角形。

### 打印文本

```scratch
將打印字體設為 [無襯線 v]
將打印字號設為 (20)
將打印字體顏色設為 [#000000]
將打印字體描邊顏色設為 [#ffffff]
將打印字體描邊寬度設為 (0)
將打印字體粗細設為 (400)
將打印字體斜體 (關閉 v)
在 x: (0) y: (0) 處打印 [你好]
```

這些積木配置一種字體，然後在給定位置將文本繪製到舞臺上。描邊設置為文本添加輪廓，*粗細*控制粗體程度。

## 提示

- 畫筆繪製位於舞臺的畫筆層，與角色分開。*全部擦除*是清除它們的唯一方法（除了重新繪製）。
- 要在高分辨率下獲得清晰的線條，請啟用高質量畫筆插件。請參閱[高質量畫筆](/advanced/high-quality-pen)。
