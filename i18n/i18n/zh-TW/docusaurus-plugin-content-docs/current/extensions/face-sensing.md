# 人臉感知

**人臉感知**擴展檢測網絡攝像頭中的面部，並報告其特徵的位置，因此角色可以跟隨您的鼻子、坐在您的頭上，或在您傾斜時做出反應。它是一個遠程擴展，不與編輯器捆綁。

從**添加擴展**加載它並選擇**人臉感知**。

## 遠程加載，需要攝像頭

人臉感知不與編輯器捆綁。您第一次加載它時，RemixWarp 會從遠程 URL 下載它，因此您需要互聯網連接來加載它（一旦加載並保存，它會隨項目重新加載）。與視頻偵測一樣，它需要網絡攝像頭權限才能運行。

## 積木

該擴展提供幾組積木：

- **面部檢測**：一個在*檢測到面部時*運行的帽子積木，以及一個布爾積木*檢測到面部?*，讓您可以在腳本的任何地方檢查面部。
- **面部大小**：一個*面部大小*報告積木，報告檢測到面部的大小，以及一個將角色大小設置為與面部匹配的命令。
- **面部傾斜**：一個*面部傾斜*報告積木、一個在*面部向左或向右傾斜時*運行的帽子積木，以及一個讓角色朝向傾斜方向的命令。
- **特徵位置**：報告面部部位位置的報告積木，包括兩眼之間、每隻眼睛、鼻子、嘴、每隻耳朵和頭頂，以及一個將角色移動到這些部位中任何一個的*移到*命令。

確切的積木措辭來自擴展本身；在編輯器中打開它查看完整列表。

## 提示

- 一次只跟蹤一個面部，因此這最適合單個人在光線合理的情況下面對攝像頭。
- 將*移到*面部部位與角色造型結合，製作跟隨您面部的帽子、眼鏡或面具。
- 如果檢測無法啟動，通常是攝像頭權限或光線問題，而不是項目 bug。
