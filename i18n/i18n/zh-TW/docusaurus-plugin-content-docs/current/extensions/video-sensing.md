# 視頻偵測

**視頻偵測**擴展在舞臺上顯示您的網絡攝像頭並測量其中的運動，因此角色可以對您揮手或在攝像頭前移動做出反應。它是內置的，並且與 Scratch 兼容。

從**添加擴展**加載它並選擇**視頻偵測**。

## 需要攝像頭

視頻第一次打開時，您的瀏覽器會請求使用網絡攝像頭的權限。視頻偵測檢測攝像頭圖像中運動的大小和方向；它不識別面部或物體。面部檢測請參閱[人臉感知](/extensions/face-sensing)。

## 積木

### 當視頻運動大於 `[閾值]`

```scratch
當視頻運動大於 (10)
```

一個帽子積木，每當測量的運動超過給定閾值時運行其腳本。

### 視頻 `[屬性]` 在 `[對象]` 上

```scratch
(視頻 (運動 v) 在 (角色 v) 上)
```

當前視頻讀數的報告積木。**屬性**是**運動**（多少運動）或**方向**（朝哪個方向移動）。**對象**是**角色**（只在此角色上方的區域）或**舞臺**（整個舞臺）。

### 將視頻 `[狀態]`

```scratch
將視頻 (開啟 v)
```

將攝像頭畫面**開啟**、**關閉**或**開啟翻轉**（左右鏡像，通常感覺更自然）。

### 將視頻透明度設為 `[透明度]`

```scratch
將視頻透明度設為 (50)
```

設置攝像頭圖像在舞臺上的透明程度，從 0（不透明）到 100（不可見）。即使視頻完全透明，運動偵測仍然有效。

## 提示

- 運動是在視頻幀之間測量的，因此靜態場景讀數接近零，快速運動讀數高。
- 使用*在角色上*讓每個角色只響應自己區域的運動，例如通過揮手"按"的按鈕。
