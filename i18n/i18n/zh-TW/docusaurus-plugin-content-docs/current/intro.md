# RemixWarp 文檔

[RemixWarp](https://remixwarp.pages.dev/) 是一個基於 TurboWarp 的 Scratch 修改版。它保留了您熟悉的 Scratch 編輯器，並添加了一個將積木編譯為 JavaScript 的編譯器、大量插件與主題、項目打包器、調試器、git 版本控制、實時協作，以及完整的社區平臺與賬戶系統。

編輯器和社區站點由同一個構建提供。您可以直接在瀏覽器中訪問 [remixwarp.pages.dev](https://remixwarp.pages.dev/)，無需賬戶、無需安裝即可使用 RemixWarp。當您想發佈項目、關注他人並在設備間同步設置時，可以使用 Rotur 賬戶登錄。
