RemixWarp 為常見編輯器操作提供鍵盤快捷鍵，並且它們可以重新綁定。顯示為 `Ctrl` 的快捷鍵在 Windows 和 Linux 上使用 `Ctrl`，在 macOS 上使用 `⌘`（Command）。

## 默認快捷鍵

**文件**

| 操作 | 快捷鍵 |
| --- | --- |
| 保存 | `Ctrl+S` |
| 另存為副本 | `Ctrl+Shift+S` |
| 從電腦加載 | `Ctrl+O` |
| 打包項目 | `Ctrl+P` |
| 還原點 | `Ctrl+Shift+P` |

**編輯**

| 操作 | 快捷鍵 |
| --- | --- |
| 撤銷 | `Ctrl+Z` |
| 重做 | `Ctrl+Shift+Z` |
| 複製 | `Ctrl+C` |
| 粘貼 | `Ctrl+V` |
| 剪切 | `Ctrl+X` |

**視圖**

| 操作 | 快捷鍵 |
| --- | --- |
| 設置 | `Ctrl+,` |
| 切換全屏 | `F11` |
| 切換背包 | `Ctrl+Shift+B` |
| 切換舞臺全屏 | `Ctrl+Shift+F` |

**項目控制**

| 操作 | 快捷鍵 |
| --- | --- |
| 啟動項目（綠旗） | `Ctrl+Enter` |
| 停止全部 | `Ctrl+Shift+Enter` |

**編輯器導航**

| 操作 | 快捷鍵 |
| --- | --- |
| 聚光搜索 | `Ctrl+K` |
| 代碼標籤頁 | `Ctrl+1` |
| 造型標籤頁 | `Ctrl+2` |
| 聲音標籤頁 | `Ctrl+3` |

**素材庫**

| 操作 | 快捷鍵 |
| --- | --- |
| 角色庫 | `Ctrl+Shift+A` |
| 造型庫 | `Ctrl+Shift+C` |
| 聲音庫 | `Ctrl+Shift+M` |
| 擴展庫 | `Ctrl+.` |
| 擴展管理器 | `Ctrl+Shift+E` |

**角色和窗口**

| 操作 | 快捷鍵 |
| --- | --- |
| 複製角色 | `Ctrl+Shift+D` |
| 刪除角色 | `Ctrl+Shift+X` |
| 關閉窗口 | `Ctrl+Shift+K` |

一些功能有自己的按鍵，不在此管理器中，例如[查找欄](/editor/find-bar)（`Ctrl+F`）、[書籤](/editor/bookmarks)（`Ctrl+Alt+T` 和 `Ctrl+Alt+1` 到 `0`）、[變量管理器](/editor/variable-manager)（`Ctrl+Shift+V`）和暫停（`Alt+X`）。

## 快捷鍵管理器

打開**設置**並轉到**鍵盤快捷鍵**頁面。它列出每個可重新綁定的快捷鍵，按分類分組，並帶搜索框。

- 要更改一個，點擊它的**鉛筆**按鈕，然後按新的組合鍵。`Escape` 取消。如果組合已被使用，管理器會告訴您哪個操作持有它並拒絕衝突。
- 更改過的快捷鍵顯示**重置為默認值**按鈕，一旦您有任何自定義綁定，**全部重置為默認值**按鈕就會出現。

您的自定義綁定保存到瀏覽器中，並在登錄時同步到您的賬戶，因此它們跟隨您跨設備。
