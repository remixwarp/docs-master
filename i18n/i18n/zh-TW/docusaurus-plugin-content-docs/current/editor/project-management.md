本頁涵蓋項目的生命週期：開始新項目、保存它（到電腦或您的 RemixWarp 賬戶）、重新加載它、分享它和改編它。這些操作中的大多數位於[文件菜單](/editor/menu-bar)中。

## 新項目

**文件，新建**清空工作區並開始一個帶一個角色（Misty）的全新項目。如果當前項目有未保存的更改，會先警告您，因為新項目會替換打開的內容。

## 保存

項目可以保存到兩個獨立的地方：作為文件保存到電腦，或在線保存到您的 RemixWarp 賬戶。它們不衝突；一個項目可以同時保存到兩者。

### 保存到電腦

- **文件，保存到（文件名）**或**另存為**將 `.sb3` 文件寫入磁盤。在支持文件系統訪問 API 的瀏覽器上，保存可以寫回您打開的文件；否則會正常下載。
- **文件，從電腦加載**（`Ctrl+O`）從磁盤打開 `.sb3`。

`.sb3` 是一個單一的自包含文件：一個 ZIP 歸檔，包含 `project.json`（所有角色、腳本、變量和設置）以及每個造型和聲音。它是項目的可移植、離線副本，可在 Scratch、TurboWarp 和 RemixWarp 中工作。

### 保存到 RemixWarp

當您用[Rotur 賬戶](/getting-started/introduction)登錄時，文件菜單顯示**保存到 RemixWarp**（項目存在於那裡後，**立即保存** / `Ctrl+S` 會保存到您的賬戶）。這會將項目上傳到您的賬戶，讓您可以通過社區站點從任何設備訪問它。

- 上傳**不是**發佈。已保存的項目在您分享之前對您保持私有。
- RemixWarp 高效上傳資源，只發送它尚未擁有的造型和聲音，因此重新保存項目很快。

要製作獨立保存的副本，請使用**文件，另存為副本**（`Ctrl+Shift+S`）。

## 分享

分享是在社區站點上進行的，而不是通過編輯器的保存操作。項目保存到您的 RemixWarp 賬戶後，打開它的項目頁面（**文件，查看項目頁面**，或[菜單欄](/editor/menu-bar)中的賬戶區域）並使用那裡的**分享**按鈕。分享使項目對他人可見，並給它一個公開頁面和播放器。您從站點控制可見性。

## 改編

**改編**基於現有項目開始一個新項目，並註明原作者。**文件，改編**（登錄時是**改編到 RemixWarp**）創建您自己的副本，您可以更改並單獨保存，不會觸及原件。改編是您基於別人的共享項目構建的方式。

## 自動保存與還原點

您工作時有兩個安全網在運行：

- [還原點](/editor/restore-points)定期將整個項目快照到您的瀏覽器中，這樣您可以在出錯或崩潰後回滾。
- 可選的[自動保存](/editor/restore-points)按計時器將項目重新保存到當前位置。

兩者都不能取代刻意保存，但都能降低忘記保存的代價。
