**打包器**將項目變成獨立應用：一個 HTML 文件、一個 zip，或 Windows、macOS、Linux 的原生應用，無需編輯器即可運行。它是一個獨立的工具，編輯器可以直接將當前項目交給它。

## 打開打包器

**文件，打包項目**（`Ctrl+P`）打開[RemixWarp 打包器](/packager/overview)，並加載好您打開的項目。您也可以單獨訪問 [packager.02engine.org](https://packager.02engine.org/) 並在那裡加載 `.sb3`。

## 打包是做什麼的

打包是您在 RemixWarp 站點之外分發完成項目的方式：

- 一個可以在任何地方託管或離線打開的單個 **HTML 文件**。
- 一個包含 HTML 及其資源的 **zip**。
- 用於桌面平臺的原生**可執行文件**。

打包輸出嵌入 RemixWarp 的運行時和編譯器，因此打包項目以您選擇的[設置](/editor/settings)以全速運行。您可以在打包器本身中自定義加載屏幕、控件、雲變量行為等。

## 分享與打包的區別

這些是不同的事情：

- **分享**項目（從其[項目頁面](/editor/project-management)）將其發佈在社區站點上，人們可以在瀏覽器播放器中玩它。
- **打包**產生一個您自己擁有和分發的文件，不依賴 RemixWarp 站點。
