title: 實時協作

實時協作讓幾個人同時實時編輯同一個項目。每個人都在自己的編輯器中工作，積木、角色、造型和聲音的更改在所有人之間同步，實時光標顯示誰在哪裡工作。

::::warning
實時協作是一個 alpha 功能，仍處於早期開發階段。在協作會話中編輯的項目可能被損壞或破壞。使用它時請保留自己的[還原點](/editor/restore-points)或保存的副本。
::::

## 開始或加入會話

打開**工具**菜單並選擇**實時協作**。窗口顯示您將以什麼用戶名出現，以及兩個選項：

- **創建新房間**：主持一個房間。您會得到一個房間代碼（以及可以分享的 URL），其他人用它加入。您是房間的**主持人**。
- **加入現有房間**：輸入房間代碼加入別人主持的房間。

分享房間通過發送它的 URL 完成，URL 攜帶一個 `?room=` 代碼；打開該鏈接會自動加入房間。

## 會話期間

連接後，窗口列出房間中的每個人。每個人顯示他們的頭像和名稱，在相關處顯示**主持人**或**您**徽章，以及他們在做什麼的實時描述，例如"正在編輯 Sprite1 中的代碼"或"正在編輯舞臺中的造型"。在工作區中，您會看到其他人的**光標**帶名稱標籤，在他們移動時顯示。

**複製房間 URL 以分享**複製邀請鏈接，**離開房間**斷開您的連接。

## 主持人控制與隱私

創建房間的人是主持人，有額外控制：

- **踢出**任何其他參與者。
- 將房間設置為**公開**（任何有代碼的人都可以加入）或**私有**（人們必須請求批准）。
- 在私有房間中，**批准或拒絕**每個待處理的加入請求。

當您加入私有房間時，您會等待主持人批准您，然後才能進入。

::::note
主持人轉發每個人的編輯，這意味著主持人可以看到加入者的 IP 地址，而在您創建的房間中，加入者可以看到您的。窗口中的隱私聲明在您主持或加入之前會說明這一點。
::::

## 協作與 git 的區別

實時協作用於在同一時刻一起編輯。對於異步團隊合作（人們分別做更改，之後再合併），請改用[git 版本控制](/editor/git)。
