# 變量和列表

變量存儲單個值（一個數字或一段文本）。列表按順序存儲許多值。兩者都位於積木區的**變量**分類中，並且都用該分類頂部的按鈕創建。

## 建立一個變量

1. 打開[積木區](/editor/blocks-palette)中的**變量**分類。
2. 點擊**建立一個變量**。
3. 輸入名稱並選擇作用域（見下文）。
4. 點擊**確定**。

您的新變量會出現在積木區中，帶有 `設`、`增`、`顯示`和`隱藏`積木，以及一個可以放入任何輸入的報告積木。

列表以相同方式工作：改為點擊**建立一個列表**。列表帶有添加、刪除、插入、替換和讀取項目以及檢查其長度和內容的積木。

## 作用域：所有角色 vs 當前角色

建立變量或列表時，您選擇兩個作用域之一：

- **適用於所有角色**（全局）：每個角色和舞臺共享同一個變量。從一個角色更改它，到處都會更改。用於分數或遊戲狀態等整個項目都關心的內容。
- **僅適用於當前角色**（局部）：變量屬於當前選中的角色。其他角色看不到它，角色的每個克隆體都有自己的私有副本。用於健康值或速度等每個角色的數據。

舞臺只能持有全局變量，因為它沒有克隆體，也沒有"局部"可以歸屬。

::::note
兩個角色可以各自擁有同名局部變量而不衝突，因為它們確實是獨立的變量。局部變量和全局變量也可以同名；在它的角色內，局部變量優先。
::::

## 舞臺上的監視器

每個變量和列表都有一個**監視器**，即顯示在[舞臺](/editor/stage)上的小讀數。通過勾選積木區中變量旁邊的複選框來切換它，或使用 `顯示變量` / `隱藏變量` 積木。

- 將監視器拖到舞臺上的任何位置來重新定位它。
- 右鍵單擊變量監視器可在普通讀數、大讀數和可以拖動以實時更改值的滑塊之間切換。
- 右鍵單擊列表監視器可調整大小或導出/導入其內容。

監視器與項目一起保存，因此它們的位置和樣式隨之旅行。

## 高級說明

- 變量和列表值存儲為 JavaScript 字符串和數字。[編譯器](/advanced/disable-compiler)直接讀寫它們，因此大列表很快，但非常大的列表仍然消耗內存和保存時間。
- 列表比較默認不區分大小寫。[設置](/editor/settings)中的**區分大小寫的列表**選項使 `"a"` 和 `"A"` 成為不同的值，這可以以標準兼容性為代價加快列表密集型項目。
- 要一次查看或批量編輯所有變量和列表，請使用[變量管理器](/editor/variable-manager)。
